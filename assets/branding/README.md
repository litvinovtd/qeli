# Qeli branding assets

- `qeli-logo.png` — canonical 1024×1024 application icon used for the repository README.
  It is copied byte-for-byte from the existing iOS application asset and represents the
  same Q-and-link-node mark rendered by the Windows, macOS, Android, and web clients.
- `qeli-social-preview.png` — 1280×640 repository Social Preview prepared from the canonical
  icon for GitHub link cards.

When the product mark changes, update the application assets and these repository-facing
copies together so the website, clients, README, and GitHub preview remain consistent.
