# qeli web-panel assets

The admin panel ships **self-hosted** CSS/JS/fonts — no runtime CDN — so it works
on an air-gapped server reached over an SSH tunnel. The generated stylesheet and
the vendored Alpine.js / woff2 fonts live under [`../src/web/assets/`](../src/web/assets)
and are embedded into the binary via `include_*!` (served from `/assets/*`).

## Regenerate the CSS

Edit a template under `../src/web/templates/`, then rebuild the Tailwind output:

```sh
cd qeli/web-assets
npm ci --ignore-scripts  # install the exact locked dependencies
npm run build    # → ../src/web/assets/app.css (minified)
# npm run watch  # rebuild on save while developing
```

`tailwind.config.js` scans `../src/web/templates/**/*.html` for utility classes;
the component layer + design tokens + `@font-face` live in `input.css`.

Rust builds use the committed `app.css`. The CI documentation/assets job also
installs the locked Node dependencies with `npm ci --ignore-scripts`, rebuilds the
stylesheet, and rejects changes to the committed output. `node_modules/` is
git-ignored.

The build uses the pinned Tailwind compiler API. Watch mode checks the CSS,
configuration, local imports and HTML templates every 500 ms; builds run in
sequence with a fresh compiler process. A compilation error preserves the last
successful stylesheet. Restart watch mode after changing build scripts or npm
dependencies. `.css-build.json` is local compiler diagnostics and is git-ignored.

Tailwind 4 requires Safari 16.4+, Chrome 111+, or Firefox 128+; see the
[upstream browser requirements](https://tailwindcss.com/docs/upgrade-guide).

## Vendored assets (not generated by Tailwind)

- `alpine.js` — `@alpinejs/csp` 3.15.12 (`dist/cdn.min.js`), SHA-256 `566167134bb2347110904e2ced6e816d2e8d837200c158f98b72372b3bb0b9a6`, npm integrity `sha512-9jielHzVPqMlO9zQ6K1WtdhSHVX5OZfq5ZDUSVZfY10VnXRoRBx8nOadWjsG1xev/kz4EPaNN9eDFWtZSvJHxA==`
- `fonts/inter-*.woff2` — Inter (latin, weights 400–800), from `@fontsource/inter`
- `fonts/jbmono-*.woff2` — JetBrains Mono (latin, 400/600), from `@fontsource/jetbrains-mono`

Re-vendor Alpine from the exact npm package and verify both hashes above before replacing
`../src/web/assets/alpine.js`. Fonts are pinned by repository history.

Seven shipped `space-y-*` sibling rules are retained in `legacy-spacing.css`
and excluded from v4 generation. This preserves spacing of hidden Alpine form
sections and the existing component-margin cascade. Edit this local import
when changing those rules; watch mode tracks its contents.

The existing date control also retains its inner 1px block padding so the
data-cap and expiry editor preserves its shipped height.

Watch mode also tracks attempted relative CSS imports from failed compilations.
Creating or restoring such a file triggers recovery without touching input.css;
an unchanged failure does not cause an endless compilation retry.
