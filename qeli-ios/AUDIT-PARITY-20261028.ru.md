# Android / iOS: аудит функционального соответствия, 28 октября 2026

Аудит исходников `dev` для 0.8.4. Исходная база — `416db5ce`; перечисленные ниже
исправления находятся в рабочей копии. Это проверка наличия функций и конкретных
дефектов, а не доказательство отсутствия всех ошибок или сертификация iOS-сборки.
Параллельные изменения идентичности сервера, транспорта и сайта не входят в этот срез.

## Функциональная матрица

| Область Android | Состояние iOS после изменений | Где реализовано / границы |
| --- | --- | --- |
| Подключение, отключение, статус, скорости, счётчики | Есть | `AppModel`, `TunnelManager`, `ConnectionView`; Apple lifecycle требует runtime-проверки |
| TCP/UDP, plain/fake-TLS/obfs/REALITY, QUIC, AWG, PQ, padding, heartbeat, shaping, bonding, PMTU | Общая реализация | Rust whole-client core через `QeliFFI`; Swift не дублирует wire-протокол |
| IPv4/IPv6, DNS, маршруты, pushed values, локальные исключения | Есть с проверкой применимости платформе | `NativeNetworkPlan`, `QeliNativeTunnelEngine`; неподдерживаемый план отклоняется до ACK |
| Reconnect, roaming, Wi-Fi/cellular, wake | Есть; исправлены первый DNS-отказ и отмена pending update | `InitialCarrierResolution`, `IOSRoamingController`; реальные переключения на устройстве не проверены |
| Защита маршрутов / запрет обхода | Apple-механизм, не эквивалент Android lockdown | `TunnelManager.makeTunnelProtocol`: `enforceRoutes` также для split; full-tunnel capture сохраняется |
| Профили: создать, изменить, удалить, копировать, выбрать, упорядочить | Есть | `ProfilesView`, `ProfileEditorView`, `AppModel`; ограничения активного профиля и stale editor сохранены |
| INI, URI, clipboard, deep link, файл, QR; обмен ссылкой/QR | Есть; устранены два различия | `ProfileImportPolicy` сохраняет INI; `QRCode` использует AVFoundation без порога A12 |
| Ручная проверка доступности | Есть | Общий UDP probe / TCP connect; при VPN проверяется согласованный gateway |
| Автопроверка профилей и интервал | Добавлено | `ProfileAutoProbePolicy`, `AppModel`, `SettingsView`; только foreground и отключённый системный VPN |
| Шифрованное хранилище и перенос backup между Android/iOS | Есть | `ProfileStore`, `BackupCrypto`, backup в `SettingsView`; QELI-ENC-1, общий формат; Keychain runtime не подтверждён этим прогоном |
| Логи, формат времени, уровень, очистка после disconnect | Есть | `SharedTunnelStore`, `LogsView`, `AppSettings`; ошибки не стираются обычной автоочисткой |
| Текущий диагностический отчёт и opt-in отчёт последней ошибки | Добавлено | `DiagnosticJournalStore`, `DiagnosticReport`; максимум один сохранённый аварийный отчёт |
| Метрики очередей/каналов в диагностике | Добавлено | C ABI 1.17 → `CarrierDiagnosticsSnapshot` → sampler/export; отсутствующие метрики не подменяются нулями |
| Автопрокрутка полного журнала | Исправлено | `LogsView` отслеживает ID последней строки, а не неизменный размер буфера |
| Тема, RU/EN, настройки очистки и диагностики | Есть; дополнены переводы | `AppSettings`, `SettingsView`, каталоги строк, локаль виджета; системные диалоги остаются системными |
| Подключение при запуске, правила доверенного Wi-Fi | Есть | `autoConnectOnLaunch`, VPN On Demand / `TrustedWiFiPolicy`; поведение при перезапуске ОС определяется iOS |
| Виджет / системная плитка | Apple-эквивалент есть | WidgetKit, App Intent; Control Center/Lock Screen control с iOS 18 |
| Проверка обновлений | Есть, opt-in | Ограниченный публичный metadata запрос через защищённый full tunnel; установка обновления регулируется способом распространения iOS |
| Выбор произвольных приложений, include/exclude apps | Ограничение iOS | Consumer-приложение не может получить список всех установленных приложений и применить Android-правила; Per-App VPN требует MDM |
| Always-on + системный kill switch Android | Прямого аналога для custom Packet Tunnel нет | VPN On Demand не называется Always-On; принудительный Apple Always On относится к supervised IKEv2 |
| Android foreground notification, battery exemption, boot receiver | Android-специфика | На iOS используются NetworkExtension/On Demand и системный lifecycle |
| Managed configuration | Есть | `ManagedConfiguration`, MDM-шаблоны; применяется приоритет управляемой политики |

Ограничения платформы сверены с документацией Apple:
[Per-App / On Demand / Always On VPN](https://support.apple.com/guide/deployment/vpn-overview-depae3d361d0/1/web/1.0)
и [enforceRoutes](https://developer.apple.com/documentation/networkextension/nevpnprotocol/enforceroutes).

Конфиги остаются INI. JSON используется для служебных ABI-сообщений, контейнеров
backup и отчётов, не возвращает JSON-редактор конфигурации. Известные поля другой
платформы сохраняются при редактировании; это не означает их применения iOS.
Кнопки копирования IP и график из Windows не выдаются за недостающие функции Android.

## Как работают добавленные функции

**Автопроверка:** Settings → Profile availability → Automatically check profiles. Выключена
по умолчанию; интервал 30 секунд, диапазон 10–3600. Не более четырёх незавершённых
проверок одновременно и пауза между обходами не меньше 10 секунд. Выход в фон,
Connect или изменение VPN-статуса отменяет планирование; занятый native worker
удерживает слот до фактического завершения. Уже начатый UDP probe не прерывается
мгновенно: его DNS и две попытки имеют собственные сроки (обычно до 6 секунд суммарно).
Результат отменённой проверки не публикуется. Повреждённое хранилище не запускает
проверку демонстрационного профиля. Проверка обращается к адресу профиля по сети.

**Отчёты:** Log → Report. Текущий отчёт содержит время, идентификатор сессии,
категорию события и доступные числовые метрики. Свободный текст логов, имена
профилей, сетевые адреса и ключи исключены. Опция Settings → Diagnostic reports → Keep
the last error report выключена по умолчанию. Clear удаляет текущие данные и
последний аварийный отчёт; отключение опции удаляет сохранённый аварийный отчёт.
Подготовленные экспорты проверяют ревизию приватности перед выдачей системе.
Уже скопированный во внешнее приложение файл отозвать невозможно.

Журнал ограничен 500 событиями/1 МиБ, выдаваемый отчёт — 256 КиБ. Native carrier
JSON ограничен 64 КиБ и 32 строками; промежуточный файл метрик — 128 КиБ. Метрики
сохраняются отдельно от журнала, поэтому очередной sample не переписывает весь
архив событий. Период — 20 секунд и финальный sample при завершении попытки.
Счётчик local completion означает передачу локальному transport writer, а не ACK
от удалённого клиента. Недоступный final sample сохраняет последнюю известную
величину с отметкой недоступности; новая VPN-сессия очищает старые метрики.

**DNS и маршруты:** первый временный DNS-отказ использует обычные лимиты reconnect.
При ещё неизвестном адресе повторное разрешение выполняется через физический
интерфейс, чтобы установленная защита туннеля не блокировала собственный DNS.
Запрет reconnect, предел попыток и отмена сохраняются. Повторный NWPath callback
не отменяет уже ожидающий debounce; потеря и возврат той же сети считаются событием.

## Проверки и незакрытые границы

| Проверка | Результат |
| --- | --- |
| Swift: portable policies, journal, metrics, DNS recovery, QR gate | 46 тестов PASS, без предупреждений |
| Swift + настоящий Rust C API: reader, импорт, reconnect | 13 тестов PASS, без предупреждений |
| Rust C ABI, включая границы буфера, неверные handles и panic containment | 22 теста PASS |
| Native build recipes и iOS package verifiers | 41 + 20 тестов PASS |
| Синтаксис Swift в режиме Swift 5 | 116 файлов PASS; это не Apple SDK typecheck |
| RU/EN, placeholders, дубликаты | 265 ключей на язык; PASS |
| Документация и версии | 9 проверок документации и sync_version PASS |

Всего 59 исполняемых Swift XCTest; Linux Swift 6.4.1, language mode 5,
Rust 1.97.0, сборки в один поток. Исходники производственной логики не заменялись
заглушками. Тестовые native-сборки на двух серверах дали одинаковый SHA256:
`d31d1e7e86eb35f8bbbf209d216c79ed024aab289863085a7b07d0ba09874a0f`.

Первый запуск native Swift-тестов сохранил 4 FAIL: Linux-библиотека намеренно
не объявляет iOS packet data-plane capability, поэтому полный Apple transport
adapter правильно отказал в создании. Тесты исправлены на реальный C lifecycle
handle и тот же production reader; отказ неподдерживаемого full adapter проверяется
отдельно. Проверки capability не ослаблены. Это не успешный запуск iOS VPN на Linux.

Компактные логи, хеши исходников и первоначальный FAIL сохранены в рабочем каталоге
`mobile-parity-20261028`; временные сборки и компилятор удалены. На `.10` освобождено 4,42 ГБ;
отдельная сборка `.11` также удалена. Исходные архивы аудита не затронуты.
Платформенные XCTest маршрутов и UI/камеры, а также два теста app-owned native
wrapper требуют Apple CI и остаются NOT_RUN. Сырой C fixture ограничен Linux: на Apple
тестовый bundle использует библиотеку приложения, не линкует вторую копию Rust registry.
После этого разделения выполненное тело Linux-тестов сохранено без изменений.
Проверяются реальные исходники переносимых Swift-модулей и новый Rust C API,
без заглушек production-логики. Изолированный Rust-срез исключает параллельные
изменения других задач. Linux Swift не заменяет Apple SDK/Xcode и не подтверждает
работу камеры, Keychain, WidgetKit, NetworkExtension или OS callback на устройстве.

До установочной iOS-сборки нужны пересборка XCFramework ABI 1.17 и Apple CI
(app + Packet Tunnel + widget + XCTest); физический smoke/interop остаётся
отдельной квалификацией. Старые библиотеки не переименованы в новые и их provenance
не переписан. Релиз этим аудитом не публикуется.

Исторические решения аудита 37/37 не меняются: принятое ограничение Android API34
ENONET остаётся неисправленным, первичный FAIL сохранён; исключённые пользователем
физические стенды не превращены в PASS.
