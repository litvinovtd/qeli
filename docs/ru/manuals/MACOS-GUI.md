# Отрисовка и память интерфейса macOS

Русский · [English](../../eng/manuals/MACOS-GUI.md)

Начиная с разрабатываемой **0.8.4**, интерфейс Qeli для macOS явно использует
программную отрисовку Avalonia/Skia (`Software`). Изменение применяется после
пересборки и установки нового приложения; обновление сервера его не включает.

## Как работает режим

Интерфейс рисуется на CPU в буфер изображения. В список рендереров Avalonia Native
включён только `Software`: автоматического выбора OpenGL или Metal для отрисовки
Qeli больше нет. Окна, меню, трей и вывод изображения на экран по-прежнему
обслуживаются macOS. Это не отключает GPU всей системы или оконный композитор.

Настройка относится к приложению, не к VPN-профилю: отдельного INI-параметра или
переключателя в настройках нет. Она действует для Intel и Apple Silicon.
Транспортное Rust-ядро, криптография, utun, DNS, маршруты и права службы не меняются.
Headless-служба launchd выполняется до инициализации Avalonia и не создаёт GUI.

Цель — снизить затраты памяти на аппаратный графический контекст и его ресурсы
для сравнительно простого интерфейса VPN. Возможная цена — дополнительная нагрузка
CPU при обновлении журнала, изменении размера окна и анимации. Поэтому снижение
памяти оценивается вместе с плавностью, CPU и энергопотреблением.

## Журнал и скрытое окно

Журнал ограничен 256 Ки символов на профиль; буферы использованных профилей
суммируются. Отображение обновляется не чаще раза в 250 мс и только при изменении.
Undo/redo для журнала выключен. При скрытии или минимизации отображаемый текст
освобождается, таймеры статистики и анимации приостанавливаются. Сбор журнала и
VPN продолжаются; закрытие окна в трей не завершает процесс приложения.

## Как проверить расход памяти

Сравнивайте сборки на одном Mac с одинаковыми архитектурой, профилем, размером
окна, масштабом экрана и уровнем журнала. Apple Silicon сравнивайте с arm64-сборкой;
запуск x86_64 через Rosetta — отдельный вариант измерения.

1. Полностью завершите прежний GUI и запустите новую Release-сборку без отладчика.
2. Измерьте память после прогрева и через 10 минут: без VPN, при подключённом VPN
   с обычным журналом и со скрытым окном.
3. Несколько раз откройте настройки, измените размер и скройте/покажите окно.
   Проверьте, стабилизируется ли память после повторных действий.
4. Запишите показатели GUI и launchd-службы отдельно, а также CPU и отзывчивость.

Для выбранного PID доступна команда только для чтения:

```sh
vmmap -summary PID
```

Сравнивайте physical footprint и распределение native/graphics памяти, а не только
размер managed heap .NET или виртуального адресного пространства. При необходимости
используйте Instruments Allocations/VM Tracker.

**170 МБ не являются гарантированным результатом или измерением этой сборки.**
Фактические RAM/CPU и поведение Intel/Apple Silicon требуют проверки на Mac.
Компиляция и headless self-test не заменяют такой замер.

## Проверки разработчика

Из корня репозитория с SDK из `global.json`:

```sh
dotnet build qeli-mac/QeliMac/QeliMac.csproj -c Release -r osx-arm64
dotnet build qeli-mac/QeliMac/QeliMac.csproj -c Release -r osx-x64
dotnet build qeli-mac/QeliMac/QeliMac.csproj -c Release -p:QeliBuildTools=true
dotnet qeli-mac/QeliMac/bin/Release/net10.0/QeliMac.dll ui-memory-selftest
```

Self-test проверяет реальный Avalonia TextBox, пакетное отображение, освобождение
старого текста и сохранность журнала. Он не читает профили, не запускает VPN и
не подтверждает снижение GPU/RSS на macOS. Изменение рендерера не является
квалификацией или публикацией нового релиза.
