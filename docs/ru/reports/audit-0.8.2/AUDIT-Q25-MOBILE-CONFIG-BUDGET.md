# Q25-F170: предел мобильного клиентского INI

1 октября 2026. База: 8dabbac7. D08 остаётся **IN_PROGRESS**.

Android ограничивал файловый импорт и отдельную запись профиля 1 МиБ, iOS — файловый импорт и запись архива тем же 1 МиБ. Общий config editor и native client принимают максимум 256 КиБ. Поэтому мобильные клиенты сначала читали/удерживали до 1 МиБ, а затем тот же профиль всё равно отвергался ядром. Кроме поздней ошибки это оставляло ненужное расхождение лимитов в store и backup.

Мобильные ранние пределы отдельной конфигурации теперь равны 256 КиБ; пределы целого контейнера бэкапа (8/12 МиБ) не менялись. Android показывает правильные единицы KiB для файла меньше 1 МиБ. Значение 256 КиБ включительно допускается к общему парсеру; превышение отсекается до передачи текста в ядро.

Проверки: Android `:app:compileDebugKotlin` и 34 `ConfigImportRangesTest` прошли с ранее проверенной host DLL ABI 1.16; `git diff --check` прошёл. iOS сборка не запускалась из-за отсутствия Mac/Xcode, как оговорено для стенда. Реальный file picker и backup restore на устройстве в этом пакете не проверялись. D08 остаётся открытым.
