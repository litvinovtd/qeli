# Q25-F198 — бюджет прямого импорта qeli://

Статус: 1 октября 2026. Публичный `ClientLink::from_uri` вызывался не только общим редактором, который уже ограничивал документ 256 КиБ, но и напрямую панельным `POST /api/client/import-link`. Поэтому длинный URI проходил разбор query и percent-декодирование без этого предела до записи профиля.

Парсер теперь отвергает вход длиннее 256 КиБ до выделений под decoded значения. Граничный тест проверяет допустимый размер и отказ при добавлении одного байта. Результаты на Windows: 1552/1552 переносимых Rust-теста PASS (1 ignored), 54/54 интеграционных теста `config_editor` PASS. Это ограничивает один запрос, но не заменяет общий HTTP body limit или нагрузочный тест панели.

D11: `provenance.py --check` ожидаемо сообщает STALE — текущие release native cores ещё относятся к старому исходному digest; A/B release-пересборка не выполнена. D12: после сброса VM `.11` отвечает на SSH, но отвергает пароль `root`; Android instrumentation остаётся непроверенной на текущем SHA.

В локальной проверке D11 обнаружен устаревший исходный инвариант в `test_native_recipes.py`: он искал прежний `load_users_db`, хотя `check-config` и runtime уже вызывают общий `load_users_db_for_runtime`. Проверка обновлена по действующему пути; 69/69 Python-тестов native-рецептов PASS. Это не заменяет A/B сборку release-ядер.
