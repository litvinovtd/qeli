Сохранение и импорт используют общий in-process mutex и sidecar lock, затем читают файл под блокировкой. Сохранение проверяет ревизию, а импорт допускает только отсутствующее имя даже при переданном API-клиентом токене. Перед атомарной публикацией выполняется ещё одно чтение для обнаружения ручной правки во время валидации. Ошибка чтения или конфликт останавливают запись. Raw INI сохраняет исходные пробелы и конечный перевод строки; автоматическое назначение dev по-прежнему может дополнить файл.
