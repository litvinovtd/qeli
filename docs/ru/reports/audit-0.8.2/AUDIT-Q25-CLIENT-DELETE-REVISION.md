# Q25-F166: устаревшее удаление и применение клиентского INI

1 октября 2026. База: 5ea46043. D08 остаётся **IN_PROGRESS**.

Delete в панели сперва останавливал туннель, а потом удалял файл без ревизии. Вкладка, открытая до чужой правки, могла остановить и удалить новый профиль. Сохранение INI работающего клиента отвечало просто Saved, хотя Linux-клиент считывает файл при старте процесса и продолжает работать со старой конфигурацией даже во внутренних циклах reconnect.

Список профилей теперь отдаёт ревизию точных байтов прочитанного INI. Панель передаёт её в HTTP-заголовке X-Qeli-Revision при Delete. API требует совпадения под общим mutex и sidecar lock до Disconnect: отсутствующий или устаревший токен не останавливает туннель и не удаляет файл. После graceful Disconnect файл читается ещё раз; ручная правка в этом окне сохраняется и возвращает конфликт. Такой поздний конфликт уже может оставить туннель остановленным, поэтому клиенту нужно перечитать профиль и при необходимости нажать Connect. Прямые API-клиенты Delete должны передавать X-Qeli-Revision из списка профилей.

Успешный Save работающего профиля возвращает requires_reconnect; панель явно предлагает Disconnect и Connect для применения нового INI. Автоматического перезапуска нет: изменение маршрутов или kill switch требует осознанного действия администратора. Для файла больше 256 КиБ или с неверной кодировкой панель не получает ревизию и не выполняет Delete; такой файл устраняют на хосте после проверки.
