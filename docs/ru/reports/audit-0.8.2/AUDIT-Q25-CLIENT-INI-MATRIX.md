# Q25-F197 — матрица общего INI-редактора

Статус: 1 октября 2026; полный адресный набор на Windows PASS. Продуктовый код в этом пакете не менялся: найденных расхождений нет.

Новый интеграционный тест берёт все 84 поля из фактической схемы (81 `[qeli]` и 3 `[logging]`), задаёт каждому явное значение и проверяет `import → runtime → import` на равенство всей карты значений. Связанные случаи заданы допустимо: `mode = plain`, `mtu = 1400`, `exit_node = true` вместе с `gateway = false`. Это ловит потерю полей при материализации для клиентских адаптеров, включая file-only настройки.

Второй тест выполняет 1000 детерминированных сочетаний ключей и значений, включая неизвестные и повторные ключи, кавычки, пробелы и вкладки. Каждый случай обязан пройти `import → export → import` с теми же типизированными значениями и исходными записями; пропуск невалидных для runtime комбинаций здесь намеренный, поскольку export сохраняет черновики. Общий `config_editor`: 54/54 PASS (`--no-default-features --offline`), rustfmt PASS. Это не coverage-guided fuzzing и не проверка UI/конкурентной записи; D08 остаётся IN_PROGRESS.
