# Q25-F117: DNS firewall серверного профиля вне async executor

Дата: 25 сентября 2026. Исходный коммит: `540b784a`. D05/D09/D10: частичное закрытие.

## Подтверждённая проблема

В `run_profile_generation` установка DNS INPUT/REDIRECT выполнялась синхронно
в async-задаче, отдельно для основного адреса и IPv6 dual-stack. Команды
iptables/ip6tables и чтение состояния могли задержать единственный executor.
При отмене ожидающей задачи результатом worker может стать `DnsInputLease`,
чей `Drop` сам запускает блокирующую очистку. Если уничтожить этот результат
на другом потоке после потери сетевого namespace, очистка будет выполняться
в неверном контексте.

## Исправление

Обе установки DNS firewall выполняются через присоединяемый host worker.
`profile_teardown::blocking` теперь передаёт результат вызывающей задаче
только после явного принятия. При отмене ожидания канал принятия закрывается:
worker освобождает непринятый lease в своём исходном namespace, затем
присоединяется до уничтожения внешнего guard профиля. Принятый lease, как и
раньше, переходит в `ProfileTeardown`. Порядок операций и INI-контракт не
менялись. Тест отмены проверяет поток уничтожения непринятого результата;
тест отзывчивости executor использует причинный gate вместо таймингового
счётчика, зависевшего от нагрузки CI.
