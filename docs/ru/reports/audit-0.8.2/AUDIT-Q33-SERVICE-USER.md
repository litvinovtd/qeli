## Находки и исправления

- **F439 / Q33-F042:** installer, Debian postinst и default-unit `set-service-user qeli` рекурсивно передавали все файлы /etc/qeli пользователю службы, включая root0600 квитанции с паролями и резервные копии конфигов. Теперь обход файлов службы не следует по symbolic links, исключает `client-links` и `*.bak-*`, сохраняет metadata этих файлов и восстанавливает каталог квитанций root0700. Ранее изменённый владелец отдельных старых квитанций не восстанавливается; доступ к ним ограничивает приватный каталог.
- **F440 / Q33-F043:** CLI не проверял state root перед recursive chown. Для symbolic link, переданной как корень обхода, chown мог вернуть успех без исправления реального состояния, после чего root override удалялся. Теперь linked/non-directory state/receipts roots отвергаются; сохранён прежний порядок возврата ошибки исправления до удаления override. Non-root caller по-прежнему не может его изменить. Частичное исправление владельца не откатывается; отказ daemon-reload после удаления — вне этих сценариев.
- **F441 / Q33-F044:** переустановка с default qeli сохраняла прежний root override. Installer теперь применяет выбранный QELI_RUN_AS после final staged-INI validation и до публикации конфига, включая default qeli. Неверный конфиг или отказ helper сохраняют live config. Это не делает всю установку транзакционной.
