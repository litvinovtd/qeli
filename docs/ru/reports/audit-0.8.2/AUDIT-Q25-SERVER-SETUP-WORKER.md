# Q25-F116: TUN/NAT setup серверного профиля вне async executor

Дата: 25 сентября 2026. Исходный коммит: `33c40ff5`. D05/D09: частичное закрытие.

## Подтверждённая проблема

`run_profile_generation` синхронно проверял и создавал TUN, конфигурировал адреса,
MTU и queue length, затем выполнял stale NAT cleanup, IPv4/IPv6 firewall setup и
sysctl acquire прямо в async-задаче. Каждая внешняя команда имела собственный
срок, но последовательность блокировала executor. Отмена этой задачи во время
системного вызова не могла безопасно освободить уже созданный TUN до завершения
вызова.

## Исправление

Фаза TUN вынесена в `setup_profile_tun` на присоединяемом worker. Результат
`ProfileTunSetup` содержит исходные fd, имя ядра, тип устройства, подсеть и число
очередей. Пока результат не принят, закрытие fd удаляет непостоянный TUN; после
принятия очередь передаётся `ProfileTeardown`. Фаза NAT/IPv6 вынесена в отдельный
worker и начинается только после этого handoff. При отмене ожидания worker
присоединяется прежде, чем внешний guard профиля удаляет правила и закрывает fd.
Порядок настройки, ошибка при занятом устройстве, параметры INI и wire/API не
менялись.
