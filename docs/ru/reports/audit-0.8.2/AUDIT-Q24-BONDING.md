## Q24-F001: один зависший carrier останавливал здоровые потоки (P2)

Изолированный Linux baseline получал 480/480 UDP echo по 16 внутренним потокам.
После blackhole одного вторичного внешнего TCP carrier и ограниченного UDP flood
на десять секунд остановились все потоки: upload получил 11 ответов, download 68,
а за последние пять секунд оба получили ноль. На baseline также истёк timeout
контрольного ping после восстановления download: 16 проверок PASS, три FAIL;
исходные ошибки сохранены.

Очередь клиента на 4096 элементов удерживала TunPacket из малого общего
нативного пула. Зависший writer мог исчерпать пул и остановить чтение TUN для
здоровых carrier. Серверная очередь аналогично могла удержать весь общий
wire pool на 4 МиБ.

Общее ядро клиента теперь копирует bonded uplink в один фиксированный пул
не более 4 МиБ. Очередь удерживает PooledBuffer и сразу освобождает нативный
TUN-пакет, включая FIFO reservation Wintun. Очереди клиента/сервера получают
ограниченные доли с запасом для здоровых streams и временного resume-кандидата.
Fallback allocation нет; при перегрузке пакет закреплённого потока отбрасывается.
Путь single-stream TCP сохранён. Новых INI-параметров, wire-формата и публичного ABI нет.

Две новые регрессии проверяют starvation/возврат настоящего пула и граничные
бюджеты. Исправленный бинарник получил по 450 ответов от здоровых потоков за
последние пять секунд **в обоих направлениях**. Все 19 проверок PASS, включая
восстановление с теми же клиентским процессом и TUN. Заблокированный поток может
терять пакеты; исправление обеспечивает прогресс других carrier.

## Разбор слоёв

Проверены primary AUTH/server push, bearer/authenticated JOIN proofs, привязка
transcript/epoch, stream caps, admission/revocation, fixed/adaptive actors,
логические слоты и affinity фрагментов IPv4/IPv6, rate buckets по направлениям,
общие cover/stealth budgets, учёт quota, close/reconnect и освобождение задач/сокетов.
Bearer JOIN нужен для совместимости. Других подтверждённых ошибок production
или мёртвых реализаций в этом разделе не обнаружено.

Мануал описывает диапазон 1–16, обычный лимит и один временный кандидат,
fixed target/retry, adaptive ramp каждые три секунды без уменьшения ширины,
стабильные negotiated slots и прежний modulo scheduling, affinity одного flow.
Указаны дополнительный ограниченный snapshot pool и общие бюджеты сессии.
Старые замеры скорости обозначены историческими, без сохранённой даты/SHA;
здесь они не повторялись.

## Исправления обвязки и границы

Resume fixture ожидал 1/1 вместо согласованной fixed/adaptive ширины; теперь
требуется восстановить именно эту ширину. Постоянные 15% потерь в REALITY-TLS
задержали финальный control exchange iperf до timeout. Потери ограничены 18
секундами, логи каждого этапа сохраняются отдельно. Исходная ошибка сохранена
и не признана подтверждённой production-регрессией.

Raw aggregate_leak_passed остаётся false: Q24 fixtures не выполняют полную
отдельную leak matrix. Raw host_restored=false сохранён там, где отличается
только точный набор трёх ранее принятых ambient legacy firewall rules; остальные
правила с порядком и состояния должны совпадать. PID сервиса и рабочий бинарник .10 сохранены.

Лаба .11 принимает TCP/22 без SSH banner; её итоговое состояние не подтверждено.
Все тяжёлые задания выполнены последовательно на .10 с одним compiler job.
Private SDK временно архивирован в локальное временное хранилище для места под
сборки и восстановлен для JNI. Недостающие библиотеки распакованы внутри SDK.
Новый эмулятор требовал userdata 6 ГиБ и RAM 2560 МиБ; очищены неиспользуемые
кеши компиляции с сохранением загруженных файлов и рабочего бинарника. Первый
boot создал два базовых userdata-файла, сохранив исходный seed. Повторный
read-only boot неполностью инициализированного шаблона завершался timeout. Лог
ядра показал ошибку политики шифрования /data/misc до загрузки Qeli. Отдельный
новый AVD сначала инициализирован штатно (23 JNI проверки), затем его read-only
cold boot прошёл 23 JNI проверки с неизменными userdata и encryption files.
Исходный AVD сохранён; все прежние raw failures остаются в evidence. Каталог
fixture в госте теперь уникален для каждого запуска, включая повтор после инициализации.
Сетевой runtime Mac/iOS/router/Windows VM исключён
пользователем. Physical Wi-Fi/LTE/sleep-wake, NAT64 и installed-app E2E не повторялись.
60 ignored остаются исключёнными. Deployment сервиса и push не выполнялись.
Snapshot listener сравнивает все шесть полей независимо от выравнивания колонок
ss; изменение PID, дескриптора, адреса/порта и состояния по-прежнему даёт отказ.
Финальный строгий внешний JNI wrapper завершился exit0, host_restored=true без
игнорирования firewall rules. Ранние raw wrapper failures сохранены.
Конфиги только INI; служебный JSON API сохранён.
