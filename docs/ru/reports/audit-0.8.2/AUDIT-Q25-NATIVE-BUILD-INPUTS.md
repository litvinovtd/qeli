# Q25-F199 — входы воспроизводимой native-сборки

Статус: 1 октября 2026; локальная проверка рецептов PASS, release A/B не выполнялась.

A/B-сборка синхронизировала `qeli/src` и Cargo-манифесты, но оставляла на VM прежний `qeli/.cargo/config.toml`. Такой конфиг способен изменить компиляцию при двух одинаковых проходах. Кроме того, `source-digest` не учитывал локальный Cargo config и выполняемые Python-рецепты: изменение build-команды или нормализации Mach-O не делало ранее записанное свидетельство устаревшим.

Теперь синхронизация удаляет только управляемые `src` и `.cargo` внутри выделенного каталога исходника и заново загружает локальный `config.toml`. Общий `BUILD_INPUTS` входит в digest и в проверку чистоты перед A/B и обновлением provenance: манифесты, Cargo config, обе платформенные команды и их общие helper/нормализатор. Тест меняет Cargo config и Mach-O-рецепт и проверяет смену digest и отказ старого evidence; отдельный тест проверяет сброс удалённого `.cargo` и точную передачу файла.

`python -m unittest discover -s scripts -p 'test_native_*.py' -q`: 70/70 PASS. `py_compile`: PASS. `provenance.py --check`: ожидаемый STALE с кодом 1. Фактические бинарники, A/B-хеши, ABI и Android instrumentation в этом пакете не подтверждены. Для D11 остаются чистый commit, доступ к `.10`/`.11`, A/B-сборка и проверка копий.
