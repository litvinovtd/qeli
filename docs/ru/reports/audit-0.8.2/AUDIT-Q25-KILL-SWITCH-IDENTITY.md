Маршруты и kill switch используют общий `network_namespace.rs`; второй реализации
проверки живого fd namespace нет. Владелец kill switch не удерживает fd TUN, поэтому
удаление/создание TUN между reconnect не отменяет защиту. Реестр в памяти ограничен
256 владельцами и не вытесняет незавершённую очистку. Leak overrides не обходят потерю
namespace identity. Контракты INI, API и ABI не меняются.

## Границы

Это право управления внутри живого процесса, не устойчивый crash journal. Новый
процесс использует существующие admission/recovery; legacy-цепочки и другой TUN
сохраняются для явного восстановления. Произвольную привилегированную подмену
одноимённых ресурсов нельзя атрибутировать; проверка и мутация iptables не атомарны.
Сохранённый путь команды не закрепляет executable/backend. DNS resolution, ожидание
operation mutex и полные последовательности команд оставались D05; срок `disengage`
закрыт [следующей фазой](AUDIT-Q25-KILL-SWITCH-BUDGET.md); дальнейшие фазы refresh/engage перечислены ниже. Произвольная работа
одного клиента в нескольких namespace не поддерживается; обнаружение завершается
fail-closed. Внешнее изменение семейств/адресов/правил требует согласованного восстановления.
