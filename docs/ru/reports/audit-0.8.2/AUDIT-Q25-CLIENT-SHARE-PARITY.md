# Q25-F196 — проверка пароля share URI во всех адаптерах

Статус: 1 октября 2026. После Q25-F194/F195 обнаружен старый Android-тест, который требовал экспортировать профиль с пустым паролем. Проверен весь путь: импорт старой `qeli://u:@host:443` остаётся допустимым черновиком, но повторная выдача ссылки без inline `pass` должна отказывать. Android, .NET и iOS тесты теперь фиксируют именно эту границу. Фикстуры с непустыми паролями не изменены.

Из текущего исходника пересобрана **отладочная Windows host DLL** через `build_client_core.py --debug --offline`; это тестовый артефакт, не release-библиотека и не доказательство D11. С ним Android `testDebugUnitTest --offline`: 167 тестов, 0 отказов/пропусков. .NET `QeliConformance selftest`: ALL PASS, включая новую проверку. iOS XCTest не запускался без Mac/Xcode. В штатном `C:\Android\Sdk` не найден NDK, поэтому свежий Android JNI/APK из этого коммита не собирался; instrumentation на эмуляторе .11 в этом пакете не запускался (предыдущие попытки SSH были отклонены). D08/D11/D12 остаются открытыми в указанных границах.
