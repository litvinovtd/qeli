## Находки и исправления

| ID | Приоритет | Дефект | Исправление |
|---|---|---|---|
| Q09-F003 | P2 | TCP-таймаут завершался после чтения AUTH/JOIN. Tarpit, ожидание Argon2, проверка пароля, ожидание admission и запись AUTH OK/ошибки согласования получали неограниченное ожидание | Один исходный дедлайн для отменяемых этапов. Истёкший дедлайн отклоняет даже немедленно готовый future. Таймаут AUTH OK проходит через существующий откат сессии, pool lease и iroutes |
| Q09-F004 | P2 | Полный ClientHello проверял record length, но игнорировал внутреннюю handshake length, хвост extensions и некорректные key-share vectors. PQ extractor принимал только 1184 байта без обязательного X25519-хвоста | Общий строгий разбор для classic/PQ extractor: версии, обе длины, session ID, cipher/compression vectors, полный TLV block, повторные extensions/groups и точные длины известных shares |
| Q09-F005 | P3 | Legacy TCP JOIN принимал произвольные байты после stream index | Точная длина `magic + token + index`; короткий JOIN и хвост отклоняются, AUTH с двоеточиями в пароле сохраняется |

Дедлайн начинается при входе во внутренний Qeli handshake. Внешние REALITY/obfs
этапы сохраняют собственные ограниченные бюджеты. Вся admission-транзакция с уже
выделенными ресурсами не отменяется целиком: ошибки отправки запускают явный откат,
который может завершиться позже дедлайна. Выполняющийся blocking Argon2 удерживает
свой concurrency permit до завершения; отмена ожидания не выдаёт его другому job.
Общий helper также используется UDP без нового отсчёта времени.

Полный ClientHello обязан содержать весь объявленный пакет; bounded REALITY peek
сохраняет отдельный контракт частичного хвоста. Неизвестные/GREASE расширения
принимаются; совпадение двух GREASE extension IDs старых builders сохраняется.
Проверка структуры не заменяет последующие проверки DH, ML-KEM и proof.
