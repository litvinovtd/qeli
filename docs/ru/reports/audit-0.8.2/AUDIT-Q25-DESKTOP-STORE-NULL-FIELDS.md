# Q25-F191 — null в полях desktop-профиля

Статус: исправлено и проверено локально 1 октября 2026.

System.Text.Json допускает явный null для свойств, объявленных в C# как обязательные строки и коллекции. Поэтому повреждённый или старый profile store мог пройти проверку Id, попасть в список Windows/macOS и вызвать исключение позднее, например при вычислении Endpoint через Protocol.ToUpperInvariant() или при передаче коллекций в native core.

Общий ProfileStorePayload теперь проверяет обязательные скалярные поля, коллекции, элементы коллекций и значения словарей при Decode и Encode. Отсутствующие поля продолжают получать штатные значения модели, а допустимые nullable поля остаются nullable. Невалидный store сохраняется механизмом карантина; действующий файл не заменяется пустым списком без сохранения исходных байтов.

Адресные conformance-кейсы: null Protocol, IncludeRoutes, элемент DnsServers, значение CarriedKeys при загрузке и null Protocol при записи — PASS. Полный QeliConformance selftest с host native ABI 1.16 — ALL PASS. Сборки QeliWin и QeliMac --no-restore — 0 предупреждений, 0 ошибок. Физический runtime Windows/macOS не проверялся согласно решению пользователя о недоступных стендах; D08 остаётся IN_PROGRESS.
