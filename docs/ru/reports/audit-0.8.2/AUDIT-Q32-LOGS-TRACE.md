## Ошибки и исправления

| ID | Ошибка | Исправление |
|---|---|---|
| F385 / F006, P2 | После проверки канонического пути файл можно заменить внешним симлинком или FIFO. Второе File::open читает за пределами whitelist или блокируется. | Канонический путь проходится через принадлежащие задаче дескрипторы каталогов с NOFOLLOW на каждом компоненте; NONBLOCK и fstat отклоняют специальные файлы. Tail читает тот же конечный fd. Стабильные внутренние симлинки разрешаются до открытия; подменённые отклоняются. Ротация не перенаправляет открытый inode. |
| F386 / F007, P2 | Авторизованные запросы независимо ставят spawn_blocking в очередь; каждый выделяет окно 4 МиБ и производные строки. | На процесс допускаются четыре задачи; слот берётся до постановки и удерживается задачей после отмены HTTP. Занятость возвращает ok=false. API-фильтр ограничен 1024 байтами UTF-8. |
| F387 / F008, P3 | Любой ненулевой offset отбрасывает первую строку, даже если это её настоящая граница. Окно без newline возвращает неполный фрагмент вопреки контракту. | Проверяется один предыдущий байт: полная первая строка сохраняется, неполный префикс отбрасывается. Нулевой cap возвращает пустую строку; lossy UTF-8 сохранён. |
| F388 / F009, P2 | File::create trace следует симлинку и обнуляет его цель, зависает на FIFO и уничтожает прежнюю выгрузку до завершения новой. Обработчик сигнала пишет непосредственно в потоке Tokio. У параллельных public dump нет допуска. | Используется существующий атомарный приватный writer: снимок форматируется, публикуется rename с правами 0600. Допускается одна выгрузка; слот удерживается во время blocking I/O и после отмены. Запись по сигналу вынесена в spawn_blocking. Ошибка до публикации сохраняет цель; ошибка финального fsync каталога означает опубликованный результат с неподтверждённой долговечностью. |

Ошибка пути предполагает возможность заменить файл/предка в промежутке между
проверкой и открытием. Это управляемое воспроизведение гонки пути, а не показанная
неавторизованная удалённая атака. Путь trace задаётся оператором для диагностики.
Сетевая политика и формат полезного трафика не изменены.

## Проверки

Baseline-harness извлекает прежний алгоритм tail и тело записи trace. Только
стык открытия/чтения адаптирован к аргументу File. Три теста воспроизводят открытие
внешней ссылки, потерю полной строки и уничтожение цели симлинка trace. Старый
допуск задач и async-политика этим baseline не воспроизводятся: это выводы из
кода, проверенные новыми регрессиями отмены. FIFO на baseline намеренно не
запускается без средства принудительного завершения.

Исправленный извлечённый harness проходит 11 тестов, также с UID/GID 65534 и
no-new-privileges. Trace совпадает с продуктом после нормализации CRLF; helpers логов и четыре
теста файлов/допуска извлечены без изменений. Включены продуктовый атомарный
writer и atomic_file.rs. Предупреждения unused-import только harness сохранены.
Отдельный процесс выполняет настоящие init/record/watch и два SIGUSR1:
65538 записей дают 65536 упорядоченных строк, seq от 2 до 65537,
overwritten 2, contended 0, права 0600. SIGINT завершает наблюдатель без перезаписи
выгрузки. Это проверка сигнала/кольца/I/O, а не захват настоящих VPN-пакетов.

Неизменяемый 85ea8fa9: 2434 library-тестов PASS, 60 прежних ignored;
строгий all-targets Clippy(-D warnings) и debug daemon PASS. Тесты выполняются в
изолированных net/mount/PID namespace с приватными /run,/var/lib,/var/log,/tmp.
Тест настоящего Axum-маршрута проверяет отказ без авторизации, границу фильтра
и изменённый текущий INI с внешним путём, не раскрывая содержимое файла. Baseline
сети/сервисов полного Linux-прогона сохранён. Первый архив не включал conformance;
следующий прогон выявил ошибку новой API-фикстуры без обязательного профиля.
Обе неудачи сохранены; фикстура исправлена до квалификации.
Для all-targets Clippy дополнительно не хватило release-примеров конфигов.
Полный Git-архив исправил состав входов; успешный библиотечный прогон использован
с того же коммита после проверки точных SHA исходников без повторения тестов.
Первой сборке малого harness не хватало зависимости thiserror; её ошибка также
сохранена. На .10 первоначальный baseline увидел изменение тех же трёх legacy
IPv4-правил. Только эти точные строки исключены из его guard; остальные сетевые
поля и сервисы совпадают. Команды изменения политики не выполнялись; неизменность
всего host firewall для этого baseline не заявляется.

## Ограничения и evidence

Кольцо осталось 65536 событий; выключенная запись по-прежнему требует одной
relaxed atomic load. Счётчики потерь снимаются вместе с кольцом. Автоматической
выгрузки при завершении нет. Точки записи покрывают TCP/UDP Rust-клиента и TCP
сервера; UDP сервера, пути под управлением ядра и трассировка отдельного
qeli-client не квалифицированы. Отсутствие записи не доказывает потерю. Гонки
родительского каталога trace не закрыты отдельным обходом fd, добавленным для
чтения логов. Атомарная публикация заменяет симлинк/FIFO назначения.

Допуск ограничивает задачи чтения/выгрузки, но не все буферы незавершённых HTTP-
ответов. Файловый syscall нельзя принудительно прервать; зависшая запись удерживает
слот. Логи ограничены 2000 строками и последними 4 МиБ. Ответ без файла даёт подсказки
journald, не читая его. В браузере используется x-text, локальный фильтр, фоновый
polling не перекрывает запросы, устаревшие результаты отклоняются; 118 групп Node VM, выполняющих настоящие embedded-компоненты, и статический
порог панели (11 шаблонов/1160 RU-строк) проходят. Среди них polling/отмена/
устаревшие ответы/сохранение ошибок Logs. Это не браузерный DOM/runtime-прогон. Уведомления и общая квалификация
маскирования секретов в логах остаются открыты.

Четыре native-ядра из точных исходников проходят независимые A/B и exports;
у macOS проверены load commands/ADHOC-структуры без Mac runtime и криптографической
проверки подписи. Windows ABI 22 и Android ART JNI 23 проходят на конечных байтах.
Первый JNI runtime прошёл 23 проверки, но guard guest links отказал: eth0
перешёл DOWN/noop→UP/LOWER_UP/pfifo_fast при запуске эмулятора; packages и исходные
userdata не изменились. Неудача сохранена. Квалифицированный повтор ждёт wlan0
и eth0 и пять стабильных снимков всех ссылок перед проверкой тех же native-байтов;
исходные userdata/packages/links AVD сохранены. Нет ARM-runtime, пересборки
managed-приложений и физических VPN/E2E. Разные targets/приватные caches не доказывают
герметичность между путями. Ранний desktop-прогон намеренно остановлен после
ошибки API-фикстуры; завершённый Windows pass и логи сохранены, собственный каталог
удалён перед пересборкой исправленных исходников.
