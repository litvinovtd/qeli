# Q25-F165: ограничение автозапуска и диагностики клиента

1 октября 2026. База: 2b0f294f. D08 остаётся **IN_PROGRESS**.

Во время старта супервизора проверка autostart читала каждый клиентский INI через неограниченный read_to_string. Страница Client сначала проверяла размер status.json через metadata, затем читала путь заново: файл можно было заменить между этими операциями, обойдя лимит 64 КиБ. Connect и Delete не разделяли блокировку с сохранением/импортом профиля, поэтому одновременный запрос панели мог запустить туннель во время удаления или удалить только что сохранённый файл.

Autostart теперь читает стабильный регулярный файл с лимитом общего клиентского INI 256 КиБ. Статус читается из одного стабильного снимка с лимитом 64 КиБ; неверный или чрезмерный status.json игнорируется и доступен прежний log fallback. Connect и Delete сериализованы с Save/Import через общий mutex панели; Delete дополнительно берёт sidecar lock перед удалением файла. Удаление по-прежнему сначала останавливает процесс, даже если файл профиля уже исчез. После отказа Disconnect файл не удаляется.
