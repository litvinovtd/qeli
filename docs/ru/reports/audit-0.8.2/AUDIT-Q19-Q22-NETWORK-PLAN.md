# Аудит Q19/Q22: общий план DNS и маршрутов

Дата: 22–23 сентября 2026. База: `fc6f4a5dc8df7f119f2d99a6b72b08916ae7a268` плюс
незакоммиченные исправления предыдущих этапов. Разделы 19 и 22 остаются **IN_PROGRESS**.

## Область

Проверены выбор DNS после handshake, legacy IPv4 и v2, приоритет конфигурации,
ограничения семейств и числа резолверов, DNS host routes, исключения маршрутов и общий
policy API адаптеров. Просмотрен порядок Linux routes → DNS → публикация поколения;
Android/iOS/C# потребляют общий NetworkPlan. Это не полный аудит DNS proxy или OS lifecycle.

## Исправления

| ID | Приоритет | Воспроизведение и последствие | Исправление |
|---|---|---|---|
| Q19-F001 | P2 | Legacy IPv4 push внешнего DNS в split-режиме давал пустой список либо fallback, тогда как v2 принимал тот же адрес. Ограничение памяти/числа маршрутов сохранено; порядок и повторения не влияют на результат. |

Из `client/dns.rs` удалены устаревшие `planned_dns_server`, `setup_dns_for_interface`
и тест прежней политики. Большая копия setup была доступна лишь под `cfg(test)` и не
вызывалась. Восстановление DNS-состояния старых версий сохранено. Из policy API удалена
отдельная сортировка исключений: общий алгоритм корректен без адаптерной эвристики.
Конфигурации остаются INI; JSON используется только как служебный DTO.

Пять новых сценариев сначала упали на исходном коде: DNS parity, malformed push,
лимит DNS, позднее широкое исключение и объединение 1024 host-исключений. После фикса
все прошли. Дополнительно проверены все 256 подмножеств восьми адресов для IPv4 и IPv6,
перестановки/дубли, `/0`, `/32`, `/128`, точный предел и настоящее превышение лимита.

  **154 Kotlin/JVM, 0 skips**; плюс **10 прямых C ABI probes** — PASS.

  `chunks_exact_to_as_chunks` для NDP на Rust 1.98; минимальный FFI — `-D warnings`
  без исключений. Это cross-check, не исполнение Linux-тестов.
