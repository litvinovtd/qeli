# Q25-F168: файловый клиентский INI в desktop CLI

1 октября 2026. База: f396c34b. D08 остаётся **IN_PROGRESS**.

Команды Windows и macOS CLI читали файл через `File.ReadAllText`. При неверном UTF-8 стандартный декодер может подставить U+FFFD, после чего общий парсер получит уже изменённый пароль или другое значение. Кроме того, файл целиком загружался до проверки лимита конфигурации.

Оба CLI теперь используют `VpnConfig.ParseFile` из общего C# слоя: он читает максимум 256 КиБ + 1 байт, отклоняет превышение до парсинга, декодирует UTF-8 без замены неверных байтов и передаёт INI в тот же строгий парсер. Временный буфер с конфигурацией очищается после вызова. Текстовый ввод и `qeli://` по-прежнему проходят через `VpnConfig.Parse`.

Проверки: общий C# conformance `ALL PASS`, включая три новые проверки (обычный INI, неверный UTF-8, превышение 256 КиБ). Сборки `QeliWin` и `QeliMac` с `--no-restore` прошли без предупреждений и ошибок. Для conformance использована ранее проверенная host DLL ABI 1.16; macOS runtime на Mac и Windows сетевой runtime не проверялись. D08 остаётся открытым для других путей импорта и runtime адаптеров.
