В пути сохранения панели уже требовался корректный непустой Argon2 PHC-хеш администратора, но общий `WebConfig::validate_active` проверял остальные активные поля, пропуская формат хеша. Поэтому вручную изменённый INI проходил `check-config` и startup-gate; при live reload неверный хеш заменял рабочий хеш в памяти, и вход в действующую панель переставал работать. Такой же INI, записанный через панель, отклонялся до сохранения.

Проверка Argon2 PHC вынесена в общий конфигурационный валидатор, который использует и API пользователей. Активная панель с неверным непустым хешем теперь отклоняется в общем gate для `check-config`/старта; при live reload прежние пароль, настройки панели и счётчики блокировок сохраняются. Для выключенной панели скрытое значение остаётся неактивным до включения. Пустой хеш и намеренный режим `insecure_no_auth` сохраняют отдельный существующий контракт.
