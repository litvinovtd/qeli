# Q25-F140: приватные права серверного INI после записи панели

26 сентября 2026. База: `85d51e57`. D07 остаётся **IN_PROGRESS**.

Пять путей сохранения активного серверного INI в панели вызывали обычный
`write_atomic`. Эта функция наследует права старого файла, а при создании
нового использует `0644`. Серверный INI содержит хеш пароля администратора,
inline-хеши пользователей и может содержать другие секреты. Поэтому старый
файл с `0644` оставался доступным локальным пользователям после правки панели.
CLI `set-web-password` уже использовал приватную атомарную запись; архивное
восстановление отдельно нормализует права извлечённых файлов до `0600`.

Все пять путей панели теперь используют общий `write_server_config`, который
публикует новый inode через `write_atomic_private` с режимом `0600`:
структурная форма, raw INI, Quick Start, история и настройки блокировки.
Снимки истории уже записывались приватно. Одновременная проверка размера,
ревизии и rollback snapshot остаётся на прежних местах.

На изолированной Linux-лабе `.11` прямой тест начал с существующего INI
режима `0644`, записал его тем же helper, которым пользуется панель, и
проверил режим `0600` и точные байты. Также прошли 34 теста модуля редактора,
`cargo fmt --check` и строгий `cargo clippy --lib --bins -- -D warnings`.
Лог: `C:/Users/litvi/OneDrive/Documents/qeli/audit-debt-20260925/server-nat44-egress-phase/serveriniprivate.log`.

Исправление закрывает права **последующей** записи; оно не отменяет доступ к
секретам, который мог существовать до неё. D07 остаётся открытым для полной
матрицы полей и гарантий против внешней записи между последней проверкой и
атомарной публикацией.
