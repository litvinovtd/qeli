# Q25-F162: уведомления только в INI и ограниченная загрузка

1 октября 2026. База: 26c98ac1. D07 остаётся **IN_PROGRESS**.

При проверке отдельного конфига уведомлений найдено остаточное чтение notify.json с автоматическим переносом в notify.ini. Это нарушало принятый контракт «конфиги только INI». Сам notify.ini читался без ограничения размера и проверки обычного файла: повреждённый или подменённый путь мог надолго блокировать чтение либо потребовать чрезмерную память. Запись также могла создать INI больше того предела, который затем принимается при чтении.

JSON-конфиг больше не разбирается и не переносится автоматически. Если INI отсутствует, а старый notify.json ещё лежит рядом, загрузчик явно сообщает об ошибке и не меняет файлы. Настройки читаются через общий дескрипторно-стабильный INI-loader с пределом 64 КиБ; запись отвергает более крупный результат до изменения файла. Portable backup исключает старый sidecar, а restore отклоняет архив, который его содержит. Служебный JSON API и webhook-сообщения остаются.

На изолированной лабе .11 прошли 4 теста notify.ini, 27 обычных backup-тестов, форматирование и строгий Clippy для серверной и client-only сборок. Оба native root-теста backup/restore повторно прошли в отдельном namespace. Логи: notifyinionly2.log и notifyinionly3.log в C:/Users/litvi/OneDrive/Documents/qeli/audit-debt-20260925/server-nat44-egress-phase. Работающая служба .10 не менялась.
