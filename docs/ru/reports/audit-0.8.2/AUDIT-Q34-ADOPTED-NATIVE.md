# Q34 — нативные библиотеки после принятия исправлений панели

<!-- normative-sync: audit-q34-adopted-native-v3 -->

13 октября 2026 года. Исправления сборки CSS панели, удаление небезопасного
legacy entrypoint и исправление Bash-маркера приняты локальным коммитом
`da776fb892bd6c02b34194a8e772770744832a77`. Native digest принятого исходного
кода: `27b85c8164e85def83c7c08575e5c3ac1b17d638b52f1cb8c8cf83a1fb5ea17e`.

До принятия патча на .11 прошли Rustfmt, strict Clippy, два целевых теста
embedded assets и полный factory release build. Его CLI `15c34473` затем
прошёл 131 реальную HTTP-проверку страниц, assets, auth, CSP, CSRF и INI.
Первоначальные отказы неполного source cut, пустого test filter и CRLF wrapper
сохранены; финальные результаты относятся к исправленным входам и фильтру.

На .10 заново выполнены независимые сборки A/B Windows x64 и macOS universal
x64/arm64; на .11 — Android ARM64 и x86_64. Использованы закреплённые штатные
рецепты, Rust 1.97.0, offline/locked/jobs1, отдельные target-каталоги и
`panic=unwind`. Проверены 327 исходных входов. Все четыре пары библиотек
побайтно совпали. Для Windows и каждого среза macOS проверены точные 33
C-экспорта; для каждой Android ABI — 33 C, 21 TransportCore JNI и один
ConfigCore JNI экспорт, всего 55. Новая DLL прошла 22 реальных ABI и localhost
проверки. Запуск сетевых драйверов Windows и физический запуск macOS сюда
не входят.

Все четыре новые библиотеки отличаются по SHA от предыдущих. Поэтому прежние
пакеты и JNI-прогоны не были переподписаны. Из принятого коммита спроецированы
679 входов Android; выполнены новые instrumented release app/test APK и обычный
unsigned production APK. Проверены обе встроенные SO, подписи лабораторных
APK, отсутствие debug-флага, production rules и два уровня проверки R8 ABI.
Неизменившиеся 201 JVM-тест и lint повторно не запускались: применимость
проверена по входам, исходным XML-отчётам и их SHA с сохранением старых дат.

На .11 в одноразовом read-only API34 эмуляторе новая SO прошла 23 JNI-проверки,
а установленный новый release APK — два теста INI. SDK и исходные userdata
побайтно сохранены. Журналы архивированы и квалифицированы независимо.
Это не новая проверка VPN data plane, SIGKILL-восстановления или generic/null
DnsResolver; соответствующие ограничения Q29 остаются открытыми.

Для каждой группы сборки подтверждены очистка собственного root/архива,
удаление временного swap и восстановление исходного состояния хоста.
Runtime root эмулятора также удалён; службы, PID, бинарники, маршруты и firewall
сохранены. Первоначальные отказы desktop staging сохранены: Python
SyntaxWarning перед JSON возникал из подстановки строкового inode-cookie
в проверку `is None`. Исправлены внешние контроллеры, а не транспорт Qeli;
бюджеты, рецепты и требования к владению каталогами не ослаблялись.

В локальном checkout обновлены четыре канонические и четыре потребляемые
копии, A/B evidence, SHA256SUMS и PROVENANCE. Проверки пар копий и provenance
прошли. [Машинный результат](../../../../release/certification/evidence/q34-adopted-native-20261013.json)
содержит фактический build commit, хеши пакетов, runtime receipt и ссылки на
сохранённые локальные архивы. Пакеты: `audit-debt-20260924/q34-native-*-adopted-*`,
`q34-adopted-android-package-20261013`, `q34-adopted-android-runtime-20261013`.

Закрыт долг по обновлению native copies/provenance после принятого патча.
Q34 в целом остаётся IN_PROGRESS: сопоставление общей release certification
с новым деревом, публичный исходный срез и hosted CI этим результатом
не подтверждены. План остаётся 32/37 (86,5%). `NO_PUSH_DEPLOY_RELEASE`.


## Обновление 15 октября: rustls и работа в dev

Разработка продолжена в `dev`; исходный коммит обновления
`099258dc3719161154c7978347a017a8d90aba75` включён в её историю. Отдельная
ветка проверки больше не используется для разработки. Минимальная версия
`rustls` и единственная изменённая запись Cargo.lock обновлены до 0.23.46;
лицензионные ресурсы соответствуют этому lock-файлу. Hosted cargo audit
и полный default-набор Rust прошли: 2469 тестов, 60 ignored; проигнорированные
тесты не считаются выполненными. Прежний прогон dev отдельно подтвердил
174 XCTest, включая Keychain. Итоговый CI после объединения проверяется отдельно.

Новые независимые A/B сборки дали одинаковые пары для четырёх библиотек.
Обновлены четыре канонические и четыре потребляемые копии, SHA256SUMS и
provenance. Проверены 22 Windows ABI-сценария, точные экспорты, три новых
Android APK, 23 JNI-проверки и два установленных теста INI на API34. Ошибка
телеметрии после успешной второй Android-сборки сохранена как исходный отказ;
артефакты независимо проверены по обеим сборкам, исходным входам и архиву.

OpenWrt закреплён на этом публичном коммите: два штатных SDK download/prepare
дали одинаковый архив. Отдельно выполнены Compile/Install/BuildPackage с
Rust 1.89 и SDK 24.10.4, семь opkg-проверок, девять CLI/INI-сценариев и сверка
533 лицензионных файлов. Собственные лабораторные каталоги, процессы и
временный swap удалены; состояние рабочих служб сохранено. Повторная сборка
компилятора LLVM/Rust не потребовалась.

[Результат обновления](../../../../release/certification/evidence/q34-rustls-native-refresh-20261015.json)
содержит точные хеши и границы проверок. Старые 20 Linux-сценариев сохраняют
прежние даты, CLI и source digest: обновление зависимости не превращает их
в новый запуск. Общая release certification для объединённого дерева требует
завершения следующего шага аудита. Q29, Q31 и Q34 этим коммитом целиком
не закрываются; план остаётся 34/37. Режима обхода Android VPN нет.
