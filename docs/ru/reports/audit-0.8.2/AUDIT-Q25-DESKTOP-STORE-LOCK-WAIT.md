# Q25-F184: конечное ожидание desktop profile-store lock

1 октября 2026. База: 99edf3a7. D08 остаётся **IN_PROGRESS**.

Q25-F178 добавил общий sidecar lock, но AcquireLock сразу возвращал IOException при краткой конкуренции. Второй экземпляр мог не загрузить профили при одновременном старте или отклонить сохранение, хотя первый экземпляр освобождал блокировку через несколько миллисекунд. Для GUI загрузка происходила прямо в конструкторе окна, поэтому даже временная занятость файла становилась ошибкой запуска.

AcquireLock теперь повторяет открытие только после IOException с монотонным бюджетом одна секунда и коротким шагом 25 мс. После истечения бюджета ошибка распространяется: зависший владелец не блокирует UI бессрочно. Ошибки создания каталога и другие типы исключений не ретраятся. Проверка версии файла после получения lock остаётся прежней, поэтому ожидание не превращает устаревшую запись в разрешённую.

Conformance selftest проверяет отказ при постоянно удержанном lock, ожидание второго читателя и успешное чтение после освобождения. Общий набор PASS; сборки QeliWin/QeliMac --no-restore прошли с нулём предупреждений и ошибок; git diff --check прошёл. Межпроцессный UI-прогон в Windows VM и Mac runtime недоступен по согласованному исключению.
