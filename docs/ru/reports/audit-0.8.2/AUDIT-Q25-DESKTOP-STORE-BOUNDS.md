# Q25-F183: ограничение чтения desktop profile store

1 октября 2026. База: 220aed55. D08 остаётся **IN_PROGRESS**.

Windows/macOS ProfileStoreFile читал profiles.json целиком до расшифровки и проверки структуры. Проверка ревизии после внешней замены снова хешировала весь файл. macOS восстановление из .bak также читало неограниченное количество байтов. Повреждённый или подставленный огромный файл мог занять память и задержать запуск либо сохранение профилей.

Общий предел зашифрованного desktop store — 16 МиБ. Чтение проверяет длину открытого файла до выделения памяти и считывает его блоками, проверяя лимит повторно, если файл растёт во время I/O. Тот же бюджет действует для проверки ревизии, записи и macOS .bak. Превышение даёт IOException до расшифровки и не переносит файл в карантин: исходные байты остаются для ручного восстановления. Предел больше мобильного plaintext-бюджета 8 МиБ, чтобы оставить запас для desktop-формата и существующих профилей; строгая численная унификация всех контейнеров остаётся в D08. README обоих клиентов указывает границу.

Проверки: общий conformance selftest PASS, включая отказ oversized load, внешнюю замену на oversized файл и отказ oversized write без изменения файла; QeliWin/QeliMac build --no-restore завершились с 0 предупреждений и 0 ошибок; git diff --check прошёл. Реальный Mac runtime и Windows VM отсутствуют по решению пользователя.
