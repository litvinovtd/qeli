# Q25-F151: панель не повышает доверие к недоверенному INI

1 октября 2026. База: `324a3418`. D07 остаётся **IN_PROGRESS**.

Рабочий процесс правильно отказывался исполнять `routing.post_up/post_down` из group/world-writable INI или symlink. Но панель перечитывала такой файл без проверки доверия, сохраняла прежние хуки и публиковала результат как приватный `0600`. Это превращало недоверенную команду в доверенную после рестарта. Путь существовал в Quick Start, структурированном и текстовом редакторах, восстановлении истории конфигурации и сохранении порогов защиты от перебора. Восстановление полного архива также допускало «неизменённую» команду из недоверенного живого файла и нормализовало права восстановленного файла.

Перед всеми пятью панельными записями текущий INI теперь читается как ограниченный снимок вместе с доверием к тому же inode. Проверяется исходный pathname, поэтому canonicalize не превращает symlink в доверенный файл. Повторные чтения перед публикацией тоже проверяют права. Восстановление истории требует доверенного снимка, а архивное восстановление требует доверенного живого источника для любой сохраняемой серверной или клиентской команды. Архив без команд по-прежнему может восстанавливать повреждённый текущий файл. Вложенный `.conf` теперь сравнивается с файлом в том же подкаталоге, а не с одноимённым файлом в корне `/etc/qeli`.

На изолированном сервере `.11` прошли адресные тесты для недоверенного INI, symlink и прежней команды в архиве, существующие тесты редактора и восстановления, `cargo fmt` и строгий Clippy. Лог: `C:/Users/litvi/OneDrive/Documents/qeli/audit-debt-20260925/server-nat44-egress-phase/panelsavetrust5.log`. Сервисы не запускались и не менялись.

Если серверный INI оставлен с небезопасными правами, перед сохранением через панель администратор должен проверить его содержимое и вернуть права (`chmod 600`). Обычный редактор по SSH всё ещё не берёт advisory lock: правка между последним чтением панели и `rename` может быть перезаписана. Полная матрица полей и путей D07 остаётся открытой.
