# Q25-F187: индекс активного профиля при iOS restore

1 октября 2026. База: d4688564. D08 остаётся **IN_PROGRESS**.

iOS importJSON превращал поле active из служебного backup-контейнера через NSNumber.intValue. Boolean и дробное число могли стать 0 или 1, а неверный тип без ошибки выбирал первый профиль. Это могло восстановить не тот сервер при корректных отдельных INI-профилях.

Теперь отсутствие active допускает legacy default 0, а присутствующее значение обязано быть JSON-числом с точным целым значением внутри массива профилей. Проверка исключает CFBoolean, строку, null, дробную часть, переполнение и индекс вне диапазона до выбора профиля. Числовые 1 и 1.0 дают один и тот же индекс, как в Android Q25-F186. Этот JSON — формат backup-оболочки; формат конфигурации остаётся INI.

Добавлен XCTest через настоящий importJSON с двумя INI-профилями и наборами допустимых/недопустимых active. Статическая проверка диффа прошла. XCTest и сборка iOS не запущены: Mac/Xcode недоступны по ранее оговорённым ограничениям; результат платформенного теста не объявляется PASS.
