# Q25-F121: поздний IPv6 не обходит kill-switch

Дата: 25 сентября 2026. Исходный коммит: `28d61ac8`. D06: частичное закрытие.

## Проблема и изменение

Если `ip6tables` отсутствовал или IPv6-часть firewall не устанавливалась, успешный пустой вывод `ip -6 address show scope global` позволял запустить IPv4 kill-switch без защиты IPv6. Это только снимок: DHCPv6, RA или администратор могут добавить адрес позже. Refresh прежнее незащищённое семейство не вооружает, поэтому дальнейшая сессия могла передавать IPv6 мимо VPN.

Теперь при включённом модуле IPv6 и `allow_ipv6_leak = false` отсутствие работающего IPv6 firewall всегда отклоняет установку. Уже установленная IPv4-часть откатывается, ошибка отката сохраняется. Без IPv6 firewall допускаются только подтверждённое глобальное отключение IPv6 или явное `allow_ipv6_leak = true`. Адресный probe и его тестовые фикстуры удалены как не дающие доказательства на время сессии.

Это намеренное ужесточение для IPv4-only хоста: если модуль IPv6 включён, `ip6tables` требуется даже при отсутствии глобальных IPv6-адресов. INI-ключи, API и ABI не менялись. Пользовательские действия описаны в [CONFIG](../../manuals/CONFIG.md) и [TROUBLESHOOTING](../../manuals/TROUBLESHOOTING.md).

## Проверки и остаток

Адресная модель проверяет отказ без `ip6tables`, отсутствие адресного probe, откат IPv4, сообщение при ошибке отката, явный override и подтверждённое глобальное отключение. Локально: 104 gateway и 20 portable kill-switch тестов PASS. Linux `.11`: 1/1 адресная регрессия, 105/105 gateway и 48/48 kill-switch тестов, Clippy `--lib --bins -D warnings`, а также 2/2 привилегированных packet-теста PASS. Новый native тест входит в отдельный network namespace, запускает kill-switch без глобального IPv6, затем добавляет адрес и default route и подтверждает рост счётчика IPv6 DROP. Сверены 362 исходных файла; SHA256 архива `9f15a779f5dfe87f330cf14310404debb208d970c499cbcc027505f90f732da6`. Первый Linux-прогон выявил, что фикстура «отсутствующей утилиты» зависела от наличия `/usr/sbin/ip6tables`; подмена пути сделана детерминированной, результаты выше относятся к повторному прогону. Лабораторные исходники и логи: `C:/Users/litvi/OneDrive/Documents/qeli/audit-debt-20260925/kill-switch-dynamic-ipv6-phase/`.
Динамический IPv4 default route, изменения namespace и полный набор сетевых backend остаются D06/D10. Один приватный packet-сценарий не заменяет всю матрицу.
