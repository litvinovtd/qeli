# Q25-F195 — ошибки выдачи ссылки в клиентском UI

Статус: Windows/macOS исходники собраны 1 октября 2026; iOS проверен статически, XCTest ожидает Mac/Xcode (D12).

После Q25-F194 общий редактор правильно отказывает в выдаче `qeli://` для профиля без inline `pass`. Windows и macOS создавали QR-окно без обработки исключения; это могло прервать UI-команду вместо сообщения пользователю. Оба клиента теперь показывают ошибку существующим диалогом. Android уже ловил ошибку и показывает toast.

В iOS `try?` превращал ошибку экспорта в пустую строку, после чего экран предлагал скопировать и отправить пустую ссылку. Экран теперь хранит результат генерации и при отказе показывает причину, не создавая QR и не предлагая Copy/Share. Заголовок отказа добавлен в EN/RU локализацию.

`dotnet build` для Windows и macOS: обе сборки PASS, 0 предупреждений/ошибок. iOS runtime/XCTest не проводился без Mac/Xcode; это оставлено в D12.
