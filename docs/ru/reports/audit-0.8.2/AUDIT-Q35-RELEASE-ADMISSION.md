# Q35 — допуск полного release-soak

<!-- normative-sync: audit-q35-release-admission-v1 -->

10 октября 2026 года выявлен ложный PASS в `scripts/roaming_resource_release_gate.sh`. Верхний gate принимал только нулевой код выхода дочерних скриптов и заданные числа циклов. Он не требовал результата или контрольной точки из дочернего сценария и не проверял минимальную длительность из плана. На изолированном Linux-стенде восемь пустых дочерних заглушек за **0,064 с** привели к `ROAMING_RESOURCE_RELEASE_GATE_PASS`; исходный stdout сохранён.

Теперь gate проверяет результат каждой из восьми фаз до собственной отметки PASS. TCP/UDP wire matrix обязаны закончиться с ожидаемым числом успешных режимов без ошибок; resume/grace/performance/multinode — с ненулевым числом пройденных проверок и нулём отказов. TCP resource soak должен показать финальную точку всех запрошенных циклов (не менее 10 000). UDP matrix обязана подтвердить QUIC 10 000 и каждый из трёх адаптеров по 1 000, а также собственные итоговые отметки. Измерение `time.monotonic_ns()` охватывает все фазы; общий release PASS возможен только после **28 800 секунд (8 часов)**. Короткий bounded smoke сохраняет отдельную обвязку и не затрагивается. Журнал фазы записывается во временный файл, вывод остаётся виден через `tee`, файл удаляется при успешном завершении и при отказе.

На .11 выполнены Bash syntax checks и **7 Linux contract-тестов**: полный порядок, отказ ребёнка, смена SHA бинарника, ошибочный ожидаемый SHA, пустой успешный ребёнок, отсутствующая финальная точка TCP и 8 часов минус 1 нс. Последние три теперь отказывают без итогового PASS. Тестовый clock shim существует только в fixture и имитирует границу времени; реальный восьмичасовой VPN-прогон этим блоком не заявляется. Собственный каталог стенда удалён после сверки файлов, процессов и mount points; служба сохранила PID 777/845 и SHA бинарника.

Следующий release-критерий остаётся фактическим: полный прогон на квалифицированном бинарнике, с сохранёнными журналами, ресурсами и временем. Это исправление закрывает дефект допуска, но **Q35 остаётся `IN_PROGRESS`**; общий итог — **30/37 DONE (81,1%)**.
