# Q25-F178: межпроцессная запись desktop profile store

1 октября 2026. База: 627af020. D08 остаётся **IN_PROGRESS**.

Windows/macOS profile store использовал фиксированный временный файл и заменял profiles.json без проверки изменений после Load. Два запущенных экземпляра могли перезаписать более новый список профилей, помешать друг другу через общий временный файл или перенести уже заменённый корректный файл в карантин. Это могло потерять обновлённые профили и затронуть хранящиеся в них секреты.

Общий ProfileStoreFile теперь сериализует операции двух экземпляров через sidecar lock, запоминает хеш точно прочитанных байтов и перед записью либо карантином проверяет, что файл не изменился. При конфликте операция завершается IOException, а более новая версия остаётся на диске; пользователю нужно перезапустить устаревший экземпляр. Для каждой записи создаётся уникальный временный файл, на Unix он сразу имеет режим 0600; после сброса данных файл атомарно заменяет основную версию, сохраняя предыдущую в .bak. Путь профилей и существующее шифрование Windows DPAPI/macOS Keychain + AES-GCM сохранены. README обоих клиентов описывает конфликт и файл блокировки.

Проверки: conformance selftest проверил устаревшее создание, устаревшее обновление с сохранением .bak, запрет карантина нового файла, успешный карантин и восстановление записи, удержанный lock и запись после освобождения. Сборки QeliWin и QeliMac --no-restore завершились без предупреждений и ошибок; git diff --check прошёл.

Ограничения: это согласование распространяется на экземпляры, использующие общий ProfileStoreFile. Внешний редактор, который игнорирует lock, всё ещё может записать файл между проверкой хеша и заменой. Mac runtime не проверен из-за отсутствия стенда; остальные адаптеры и runtime reconnect остаются в D08.

Сверка 2 октября: [Q25-F210](../../plans/AUDIT-DEBT.md) закрывает доступный D08, фиксирует single-writer/read-only iOS и явную границу внешних записей; 511 .NET, 167 JVM и 12 instrumentation PASS. Прежние числа и ожидания выше исторические; Apple runtime SKIPPED по решению пользователя, не PASS.
