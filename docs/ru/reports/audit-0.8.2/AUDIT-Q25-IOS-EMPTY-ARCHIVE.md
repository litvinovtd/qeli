# Q25-F180: пустой iOS profile archive не заменяется шаблоном

1 октября 2026. База: f56a9ee7. D08 остаётся **IN_PROGRESS**.

ProfileStore.load расшифровывал архив и вызывал ProfileArchive.normalize до проверки допустимого количества профилей. normalize превращал пустой набор в шаблонный профиль. Повреждённый, но корректно зашифрованный пустой архив поэтому считался успешно загруженным; следующая правка могла заменить исходные байты шаблоном. Такой же порядок в save и exportJSON скрывал пустой входной архив. Android restore и валидатор iOS требуют 1..256 профилей.

Теперь load, save и exportJSON отвергают пустой набор до нормализации. Коррекция повторяющихся legacy ID и обычное удаление последнего профиля в AppModel сохраняют прежнюю логику: AppModel создаёт шаблон до сохранения. Добавлен XCTest на отказ save/export и отсутствие записи при пустом входе; текст ошибки уточняет границы 1..256. README описывает отказ при пустом сохранённом архиве.

Проверки: статическая сверка всех трёх путей нормализации и git diff --check прошли. Swift/XCTest не запускались: Mac/Xcode/iOS стенд исключён пользователем из текущего объёма. Поэтому D12 не получает PASS для iOS; при доступе к Mac требуется сборка и выполнение теста.
