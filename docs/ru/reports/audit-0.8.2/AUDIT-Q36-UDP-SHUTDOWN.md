# Q36-F018: остановка UDP и сохранение ошибок задач

<!-- normative-sync: q36-udp-shutdown-v2 -->

Лабораторные замеры производительности невыпущенной 0.8.2 сняты с публикации. Полные исходные данные и прежние отчёты сохранены локально для внутреннего аудита. Они не являются публичным бенчмарком релиза или основанием для сравнения скорости версий.

При штатной отмене UDP receive pump закрытие канала больше не считается неожиданной аварией. Supervisor различает остановку владельца и потерю worker; завершённые ошибки и паники других задач сохраняются. Неожиданное завершение в живом профиле остаётся ошибкой. INI, ABI и wire format не меняются.

Это описание функционального исправления, не результат измерения AUTH-rate или пропускной способности.
