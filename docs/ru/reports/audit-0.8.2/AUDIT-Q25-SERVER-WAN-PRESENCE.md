# Q25-F131: наличие WAN при установке серверной маршрутизации

25 сентября 2026. База: `3570d441`. D06 остаётся **IN_PROGRESS**.

## Дефект и изменение

При `routing.nat.enabled = true` и управляемом `routing.ipv6.mode = route/nat66`
явно заданное имя WAN прежде принималось без проверки существования устройства.
`iptables -o <имя>` может сохранить правило для отсутствующего интерфейса:
если позже другое устройство получит это имя, правило начнёт действовать без
нового допуска профиля. Тот же риск есть при исчезновении автоматически найденного
WAN между ответом `ip route get` и установкой правил.

`resolve_wan_until` теперь проверяет выбранное имя через
`network_interface::index` в network namespace вызывающего worker. Неизвестное
устройство или ошибка ioctl отклоняют установку. Проверка входит в общий бюджет
операции и происходит до включения forwarding/sysctl и добавления новых правил.
`manual` остаётся администраторским режимом без этой проверки: он не ставит
управляемые IPv6-правила. Дефолтное `routing.nat.interface = eth0` по-прежнему
обозначает автоопределение IPv4; формат INI/API не менялся.
