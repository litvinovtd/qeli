# Q25-F179: Android profile store не принимает устаревшую запись

1 октября 2026. База: c7687fb7. D08 остаётся **IN_PROGRESS**.

Q25-F177 добавил ревизию UI в один MainActivity, но второй экземпляр Activity мог загрузить те же профили и позже сохранить устаревший список. Android manifest использует singleTop, что не гарантирует единственный экземпляр во всех task/intent сценариях. Общий encrypted SharedPreferences принимал обе записи без проверки версии. Подтверждённый restore резервной копии также мог заменить профиль, изменённый после появления диалога.

SecureStore теперь выдаёт непрозрачную версию зашифрованной записи, включая повреждённое значение, и под общей для экземпляров SharedPreferences блокировкой сравнивает её перед commit. MainActivity сохраняет наблюдённую версию при загрузке и обновляет её только после успешной записи. Устаревший commit отклоняется без изменения профилей, EN/RU сообщение предлагает перезапустить окно. Явное восстановление повреждённого store по-прежнему возможно, но тоже отказывается заменять появившуюся после загрузки запись. README описывает это поведение.

Проверки: compileDebugKotlin, assembleDebug и assembleDebugAndroidTest прошли; 156 JVM-тестов прошли с проверенной host DLL. Добавлены три Android instrumentation-регрессии: последовательный конфликт двух экземпляров, одновременная запись двух экземпляров и restore повреждённой записи. Их запуск на эмуляторе не подтверждён: сервер .11 отклонил прежний пароль root до загрузки APK; сервер .10 не затрагивался. Подготовленные APK и одноразовый read-only AVD сценарий лежат в audit-debt-20260924/android-cas-20261001; после восстановления SSH-доступа требуется прогон ожидаемых девяти тестов и проверка неизменности userdata images.

Граница: сериализация защищает экземпляры внутри процесса Android-приложения, где SharedPreferences возвращает общий объект. Внешние процессы, которые пишут тот же XML напрямую, этим контрактом не охвачены. iOS UserDefaults и runtime reconnect остаются в D08; Android итоговый стенд остаётся в D12.

Сверка 2 октября: [Q25-F210](../../plans/AUDIT-DEBT.md) закрывает доступный D08, фиксирует single-writer/read-only iOS и явную границу внешних записей; 511 .NET, 167 JVM и 12 instrumentation PASS. Прежние числа и ожидания выше исторические; Apple runtime SKIPPED по решению пользователя, не PASS.
