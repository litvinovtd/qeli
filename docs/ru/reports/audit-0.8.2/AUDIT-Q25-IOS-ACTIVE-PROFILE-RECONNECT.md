# Q25-F181: уведомление iOS о применении активного профиля

1 октября 2026. База: 4d74e72d. D08 остаётся **IN_PROGRESS**.

iOS AppModel.saveProfile разрешал менять INI активного профиля при работающем туннеле. Сохранение обновляло encrypted store и список, но Packet Tunnel Provider продолжал использовать снимок предыдущей конфигурации; редактор сразу закрывался без указания переподключиться. Это отличалось от Android, где такое напоминание уже есть, и могло создать ложное впечатление применения нового маршрута или параметров безопасности.

saveProfile теперь возвращает признак, что текст активного профиля изменился при активной фазе туннеля. После успешной записи редактор показывает отдельное локализованное EN/RU подтверждение: отключиться и подключиться снова. До подтверждения редактор остаётся открытым. Правка имени или неактивного профиля не требует сообщения. Автоматический restart не добавлен, чтобы изменение сетевой политики оставалось явным действием пользователя.

Проверки: статически сверены единственный вызов saveProfile, условие активной фазы, локализации и git diff --check. Xcode/симулятор недоступны по согласованному исключению; UI/runtime-поведение не получило платформенного PASS. D08 остаётся открытым для iOS concurrent edits, других runtime-переходов и подтверждения на устройстве.
