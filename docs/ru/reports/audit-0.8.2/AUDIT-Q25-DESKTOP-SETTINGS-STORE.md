# Q25-F192 — общее хранение настроек Windows/macOS

Статус: код и локальные проверки завершены 1 октября 2026; физический runtime macOS пропущен по решению пользователя.

Оба клиента независимо читали settings.json через File.ReadAllText без предела размера. При ошибке загрузки они пытались перенести исходник в .corrupt, но игнорировали отказ переноса и открывали резервную копию или defaults. Следующее сохранение могло перезаписать исходный файл. File.Exists также мог принять ошибку доступа за отсутствие файла.

Общий AppSettingsStore сохраняет прежний внутренний формат и UTF-16 BOM совместимость. Он читает не более 1 МиБ с проверкой размера во время чтения, отвергает неверный UTF-8, атомарно пишет приватный временный файл и ограничивает размер результата. Отсутствие файла определяется по FileNotFound/DirectoryNotFound; повреждённый основной файл сначала переносится в уникальный .corrupt. Если перенос не удался, загрузка завершается ошибкой без выдачи writable defaults. Windows и macOS удалили дублирующую файловую реализацию и используют этот слой.

Семь адресных файловых conformance-кейсов PASS: первый запуск, backup, неверный UTF-8, слишком большая запись, UTF-16 BOM, слишком большой вход и отказ карантина при открытом файле Windows. Полный managed selftest с host native ABI 1.16 — ALL PASS. Сборки QeliWin/QeliMac --no-restore — по 0 предупреждений и ошибок. Конкуренция внешних писателей и физический runtime macOS не подтверждены; D08 остаётся IN_PROGRESS.
