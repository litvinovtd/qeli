# Q25-F173: транзакции профилей в desktop UI

1 октября 2026. База: 216e7795. D08 остаётся **IN_PROGRESS**.

Windows и macOS при добавлении, импорте и дублировании сначала изменяли ObservableCollection, затем сохраняли store. Редактирование и удаление также меняли видимый список до ProfileStore.Save. При сбое диска/шифрования UI показывал профиль или правку, которых не было в сохранённом файле, либо скрывал ещё сохранённый профиль. В Windows исключения из New/Duplicate/Edit/Delete могли выйти из обработчика UI без осмысленного восстановления.

Теперь оба desktop UI сначала сохраняют предложенный список и только после успеха меняют видимую коллекцию. Ошибка показывается пользователю; список остаётся прежним. При сбое записи после остановки активного профиля Edit/Delete пытаются перезапустить прежнюю конфигурацию. После асинхронной остановки индекс редактируемого профиля вычисляется заново, чтобы не применить правку к прежней позиции списка. Служебный формат profile store не меняется; конфигурация пользователя остаётся INI.

Проверки: dotnet build QeliWin и QeliMac с --no-restore прошёл без предупреждений и ошибок; git diff --check прошёл. UI fault-injection на Windows VM и Mac недоступен по согласованным ограничениям стенда. Конкурентные операции редактирования и reconnect остаются открытой частью D08.
