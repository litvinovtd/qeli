# Q25-F182: снимок iOS-профиля при редактировании и удалении

1 октября 2026. База: 6848e3ed. D08 остаётся **IN_PROGRESS**.

iOS ProfileEditorView сохранял только UUID профиля. Если профиль удалили, пока редактор открыт, AppModel.saveProfile не находил UUID и переходил в ветку добавления нового профиля. Если содержимое профиля изменилось, старая форма могла затереть свежую правку. Подтверждение Delete в ProfilesView тоже удерживало старую строку, но перед удалением AppModel проверял только UUID.

Редактор передаёт исходный Profile. AppModel перед изменением сравнивает всю запись с текущей записью того же UUID; отсутствие или отличие даёт явный локализованный EN/RU отказ, без записи в store. Создание нового профиля остаётся отдельной веткой только для редактора без исходной записи. Delete также сравнивает подтверждённый снимок с текущим профилем и отказывается удалять новую версию. Условие reconnect из Q25-F181 по-прежнему рассчитывается после этой проверки.

Проверки: статически сверены оба вызова UI, условие сравнения до мутации, обе локализации и git diff --check. Xcode/симулятор недоступны по согласованному исключению; платформенный UI-тест не засчитан. Межпроцессная конкурентная запись iOS UserDefaults и runtime reconnect остаются в D08.

Сверка 2 октября: [Q25-F210](../../plans/AUDIT-DEBT.md) закрывает доступный D08, фиксирует single-writer/read-only iOS и явную границу внешних записей; 511 .NET, 167 JVM и 12 instrumentation PASS. Прежние числа и ожидания выше исторические; Apple runtime SKIPPED по решению пользователя, не PASS.
