## Найденные проблемы и исправления

- **F442 / Q33-F045:** native SSH смешивал stdout и успешные предупреждения nft о принадлежности таблиц в непредсказуемых местах. Сравнение ошибочно сообщало об изменении firewall. Теперь потоки собираются отдельно; stderr исключается только при rc0, а при ошибке сохраняются диагностика и код возврата. Исходный FAIL сохранён.
- **F443 / Q33-F046:** packaged ExecReload отправляет SIGHUP MainPID, но supervisor обрабатывал только SIGINT/SIGTERM. Reload завершал supervisor и worker. SIGHUP теперь устанавливается до запуска и обрабатывается управляемой задачей с обычным ограниченным shutdown. Проверенный reload обновляет users/auth supervisor и передаёт ReloadUsers worker, сохраняя блокировки входа в панель. Полная очередь объединяется с уже ожидающим restart/reload без неограниченного sender. Неверные config/users не публикуют новый auth state. Startup-only settings по-прежнему требуют restart.
- **F444 / Q33-F047:** при выборе root сохранялись только три network capabilities. UID0 не имел DAC bypass и не мог читать config владельца qeli0700/0600. Root drop-in добавляет только CHOWN/DAC_OVERRIDE/FOWNER к существующим сетевым bounds и очищает ambient capabilities root. ProtectSystem и NoNewPrivileges сохраняются; удаление drop-in возвращает capabilities qeli. Доверие к командам/публикации config не ослаблено: для сохранения через панель root должен явно владеть проверенным конфигом; helper не повышает доверие к чужим hooks автоматически.
