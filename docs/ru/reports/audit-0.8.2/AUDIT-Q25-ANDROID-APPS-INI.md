# Q25-F193 — Android per-app редактор и секции INI

Статус: исходник исправлен и проверен на JVM 1 октября 2026; UI на эмуляторе ожидает доступ к лаборатории.

Редактор выбора приложений удалял строки apps_mode/apps регулярным выражением и дописывал новые в конец INI. В профиле с последней секцией [logging] они оказывались внутри logging, после чего общий парсер отвергал сохранение. Поиск startsWith для apps_mode также удалял строки с похожими именами.

Новый узкий ProfileAppsEditor меняет только точные ключи внутри [qeli], вставляет их до следующей секции, сохраняет комментарии и остальные строки. Список выбранных пакетов сортируется для стабильного INI и чтобы повторное сохранение не показывало ложную необходимость переподключения. Он не заменяет общий парсер: результат перед записью проходит VpnConfig.parse и validate. Ошибки этой операции теперь входят в обработку ошибки сохранения диалога.

Три адресных JVM-теста покрывают [logging] после [qeli], комментарии и похожие ключи, а также отсутствие [qeli]. Полный Android testDebugUnitTest: 167/167 PASS, 0 failed/skipped с host native ABI 1.16. assembleDebug PASS. Ограничение: аппаратный UI/instrumentation этой версии не запускался; D08/D12 остаются IN_PROGRESS.
