# Q36 — итог аудита бенчмарков

<!-- normative-sync: audit-q36-final-v1 -->

Лабораторные замеры производительности невыпущенной 0.8.2 сняты с публикации. Полные исходные данные и прежние отчёты сохранены локально для внутреннего аудита. Они не являются публичным бенчмарком релиза или основанием для сравнения скорости версий.

Публичные таблицы, абсолютные значения скорости/задержек/потерь и численные сравнения из этого отчёта удалены. Статус инженерного аудита не является подтверждением производительности финального релиза. При подготовке нового публичного бенчмарка нужны согласованная методика и отдельная проверка результатов.

Опубликованный сравнительный [бенчмарк 0.8.0](../benchmarks/vpn_protocol_benchmark_repeat_2026-09-01.md) оставлен без изменений.
