# Q25-F169: текстовый клиентский INI до общего парсера

1 октября 2026. База: 81a9edae. D08 остаётся **IN_PROGRESS**.

Текстовый импорт Windows/macOS, ручной текстовый редактор обеих desktop-панелей, Android-редактор и iOS-импорт применяли `Trim`/`trim`/`trimmingCharacters` ко всему документу перед общим парсером. Такое преобразование могло удалить конечный недопустимый управляющий символ, хотя Rust INI-парсер проверяет исходные строки до их нормализации. Это также означало, что сохраняемая версия не всегда соответствовала вставленному тексту.

Все шесть входов теперь передают исходный текст общему парсеру. Нормализация имени профиля и использование обрезанной копии только для определения подписи iOS не меняют конфигурацию. Допустимые начальные пробелы и завершающий пробел ссылки `qeli://` по-прежнему обрабатываются в общем config core; INI проверяется там без предварительной потери содержимого.

Проверки: сборки `QeliWin` и `QeliMac` с `--no-restore` прошли без предупреждений и ошибок; Android `:app:compileDebugKotlin --offline` прошёл с прежним предупреждением о deprecated Android API. iOS сборка не запускалась: Mac/Xcode недоступны согласно согласованному ограничению стенда. Живой UI-путь на устройствах не проверялся; D08 остаётся открытым.
