# Q25-F174: подтверждённая запись Android-профилей

1 октября 2026. База: c2e211a1. D08 остаётся **IN_PROGRESS**.

Android MainActivity изменял список профилей или активный индекс перед записью и вызывал асинхронный SharedPreferences.apply(). Сбой записи нельзя было обнаружить: UI показывал неподтверждённые add/edit/import/duplicate/delete/move/per-app/selection. Restore backup сообщал об успехе после apply и повторного чтения, даже если новая версия ещё не была надёжно сохранена. Переход с legacy plaintext в encrypted store также удалял plaintext сразу после apply, рискуя оставить пользователя без обоих экземпляров.

Все операции изменения профилей теперь создают предложенное состояние, валидируют и записывают его через проверяемый commit до изменения UI. При ошибке видимый список и выбор остаются прежними, пользователь получает сообщение. Backup restore использует тот же путь и нормализует служебный контейнер к текущим cfg/INI записям. Legacy plaintext удаляется только после commit и read-back зашифрованной копии; нечитаемая существующая encrypted запись не запускает удаление plaintext. Неиспользуемый SecureStore.Editor.apply удалён. JSON остаётся форматом внутреннего хранилища и backup, не форматом пользовательского конфига.

Проверки: Android compileDebugKotlin прошёл; 154 JVM-теста прошли с ранее проверенной host DLL; git diff --check прошёл. Первый запуск JVM-тестов без DLL завершился UnsatisfiedLinkError и не является дефектом этого пакета; повторение с обязательным QELI_CONFIG_NATIVE_LIBRARY прошло. UI fault-injection и instrumentation этого изменения не выполнялись; синхронный commit на UI thread может добавить задержку для крупного (до 8 МиБ) store и требует отдельной оценки производительности. D08 остаётся открытым для конкурентного редактирования и runtime-проверок.
