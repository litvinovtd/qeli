# Q25-F185: структура desktop profile store

1 октября 2026. База: 38462475. D08 остаётся **IN_PROGRESS**.

После расшифровки Windows/macOS profile store десериализация корневого JSON null возвращала null, который код заменял пустым списком. Следующее сохранение могло закрепить эту пустоту поверх исходного зашифрованного файла. Массив с null-элементом проходил в UI как список профилей с пустой строкой и мог вызвать поздний сбой. Такой JSON — только внутренний контейнер зашифрованного списка; форматом пользовательской конфигурации по-прежнему является INI.

Общий ProfileStorePayload.Decode теперь требует массив как корень и запрещает null-элементы. Windows/macOS Load применяют одну проверку до допуска списка в UI; macOS .bak recovery проверяет ту же структуру. Ошибка идёт по существующему fail-closed пути сохранения нечитаемого store для ручного восстановления. Настоящий пустой массив остаётся допустимым, поскольку desktop UI разрешает удалить все профили.

Проверки: общий conformance selftest PASS для пустого массива, null-корня и null-элемента; QeliWin/QeliMac build --no-restore — 0 предупреждений и ошибок; git diff --check прошёл. Платформенный UI runtime Windows/macOS не проверен из-за отсутствия стендов.
