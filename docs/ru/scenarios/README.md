# Сценарии использования

Практические схемы применения Qeli: что настраиваем, какие данные нужны, готовые
конфиги, порядок запуска, проверка и восстановление после перезагрузки.

[Карта документации](../index.md) · [English](../../eng/scenarios/README.md)

| Сценарий | Задача | Версия и проверка |
| --- | --- | --- |
| [Клиент → A → B → Интернет](CHAINED-SERVERS.md) | Подключить клиентов к A и направить их трафик через B, сохранив собственные маршруты серверов; встроенный клиент, INI-hooks и автозапуск | Исправление reconnect в планируемой 0.8.4 проверено на кандидате; root — испытан, User=qeli — отдельная квалификация не проводилась |

Для установки самого Qeli начните с [GETTING-STARTED](../manuals/GETTING-STARTED.md).
Полные параметры находятся в [CONFIG](../manuals/CONFIG.md); здесь описываются готовые
комбинации настроек, а не дублируется справочник.
