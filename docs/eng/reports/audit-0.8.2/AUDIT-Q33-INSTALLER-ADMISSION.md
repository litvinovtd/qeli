# Q33: installer dependency and Debian package admission

<!-- normative-sync: q33-installer-admission-v1 -->

8 October 2026. F422–F426 / Q33-F025–F029. Q33 remains IN_PROGRESS. The dependency/package stage is qualified here; later config, identity, users, panel, tuning, restart and Docker integration remain open.

## Findings and changes

- **F422 / Q33-F025:** unconditional apt update/install made a complete local payload depend on reachable repositories. Only missing prerequisites are now installed; each required command and, for HTTP, the CA bundle is rechecked afterward. Local payload plus explicit public host needs no curl/jq/CA setup. Fully available remote prerequisites also skip apt. Failed index/install and false apt success cannot continue to Qeli publication. Missing account tools request adduser; the existing IPv6 capability fallback remains.
- **F423 / Q33-F026:** architecture checks admitted a different package name. Both local and downloaded Debian packages must be Package=qeli, have host architecture/all and a version. Wrong/corrupt local input refuses before dependency/config changes. Operator-supplied local package bytes remain trusted unless attestation is requested.
- **F424 / Q33-F027:** apt failure followed by failed dpkg and successful dependency repair could continue despite absent, old or unpacked Qeli. Exact dpkg-query status/version/architecture must now equal the admitted artifact. This includes Debian revision and architecture=all. No subsequent config generation is permitted on a mismatch; package/dependency changes already attempted are not rolled back.
- **F425 / Q33-F028:** required attestation was enforced for extracted binary payload but ignored by the full Debian install path. QELI_VERIFY_ATTESTATION=1 now requires gh and successful attestation verification before package installation, for local and remote packages. Release SHA sums establish integrity against release metadata; they are not independently signed sums. The comment no longer claims that provenance guarantee.
- **F426 / Q33-F029:** QELI_DEB URL support was advertised and retained as unreachable code despite the early regular-file guard. The dead branch is removed; QELI_DEB consistently means a local package file. Automatic release download remains the default when neither local binary nor package is supplied. Use an absolute local package path, as documented for apt.
