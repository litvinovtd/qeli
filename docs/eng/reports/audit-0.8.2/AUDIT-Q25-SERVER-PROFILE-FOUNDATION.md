# D07: foundational server profile fields

1 October 2026. Traced 63 fixture entries outside the `obf.*` family, including one example of each dynamic `pool.*.reservation.<user>` family. The list comes from the [fixture generator](../../../../scripts/gen_roundtrip_fixture.py); [the INI codec](../../../../qeli/src/config/server_ini.rs) provides parse/serialize. This is a static runtime trace; Q25-F152 already verifies round-trip. `obf.*` and mixed save/restart scenarios remain in D07.

| INI keys | Validation and runtime consumer |
|---|---|
| `enabled`; `[profile:*]` section name | The [shared validator](../../../../qeli/src/server/mod.rs) requires at least one enabled profile. Disabled profiles do not start and their remaining fields are intentionally not validated. The name selects identity and scopes host resources. |
| `identity_key` | Trusted-path check and private-key load before worker startup; the per-profile name supplies the default path. |
| `bind.address`, `bind.port`, `bind.transport`, repeated `listen` | Transport and listener-overlap checks; TCP/UDP listeners bind before the profile is reported ready. Extra listeners share its TUN, pool and identity. |
| `roaming.enabled`, `grace_secs`, `max_orphaned`, `max_orphan_bytes` | Feature gate and bounds; policy reaches TCP/UDP handlers and session management. Values alone do not enable roaming. |
| `tun.ip_mode`, `name`, `address`, `ipv6_address`, `mtu`, `device_type`, `tx_queue_len`, `queues` | Family, address, MTU and interface checks; [TUN setup](../../../../qeli/src/server/mod.rs) creates queues and addresses and sets TX queue length. `queues=0` is auto; explicit values above 256 are now rejected before startup instead of silently capped. |
| `pool.cidr`, `pool.exclude`, `pool.ipv6.cidr`, `pool.ipv6.exclude`, both `pool.*.reservation.<user>` | Range, cross-profile overlap and user-address checks; the allocator issues IPv4/IPv6 and reserves explicit addresses. Inactive address-family fields are retained but not applied. |
| `routing.client_to_client`, `forward_private`, `nat.enabled`, `nat.interface` | Compatibility and interface checks; client ACL/direct path, IPv4 forwarding and NAT44 are selected during profile setup. NAT44 takes precedence over `forward_private`. |
| `routing.ipv6.mode`, `interface`, `ndp_proxy`, `ndp_proxy_interface` | `off/manual/route/nat66` compatibility; IPv6 forwarding/firewall and NDP start separately. With `manual`, the administrator owns external firewall and forwarding. |
| `routing.post_up`, `post_down` | Root hooks run only from a trusted file; the panel cannot set or change them. `post_down` needs orderly shutdown. |
| Repeated `route` with CIDR/gateway/metric/description | Count/family checks, then profile or user route selection in the authentication response. `description` is INI/panel metadata, not a network rule. |
| `dns.enabled`, `listen`, `listen_ipv6`, `port`, `upstream`, `upstream_protocol`, `cache_size`, `timeout_secs`, `blocklist`, `push_servers` | Listener, upstream and resource-limit checks; the [DNS proxy](../../../../qeli/src/server/dns.rs) receives its config at startup. `push_servers` is independently advertised to clients; tunnel DNS uses the first address. Proxy fields remain stored when disabled but do not start it. |
| `dhcp.enabled`, `listen`, `pool_start`, `pool_end`, `lease_time_secs`, `domain_name` | IPv4 pool and safe-bind checks; [DHCP](../../../../qeli/src/server/dhcp.rs) receives lease bounds and options. Its remaining fields do not start the service when disabled. |
| `perf.tcp.*`, `perf.udp.*`, `perf.tun.read_buffer_size`, `perf.connection.*` | Size/limit checks, TCP/UDP socket setup, TUN reads, session admission and idle/handshake timers. TCP fields in a UDP profile and vice versa remain serialized for future transport switches but do not affect the other transport. |

Active profile fields are applied when a **profile worker generation** starts, not by live web reload. `check-config`, startup and panel writes share `validate_profiles`; SIGHUP alone does not recreate a changed profile. On isolated Linux lab `.11`, 78 server tests (including the new `0/256/257` boundary), `cargo fmt --check` and strict Clippy passed. Lab services were not changed. Static tracing of these 63 entries is not a per-combination runtime test. `obf.*`, mixed save/reload/import tests and the race with a manual editor that does not take the advisory lock remain open.
